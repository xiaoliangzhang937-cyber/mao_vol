##### 01、反对日本进攻的方针、办法和前途
### 为什么写
一九三七年七月七日日本帝国主义发动卢沟桥事变，企图以武力吞并全中国，全国人民一致要求对日作战。中共中央于事变次日（七月八日）发表号召抗战的宣言；蒋介石迟至七月十七日才在庐山发表谈话，确定准备抗战的方针。但此时平津之间的汉奸和亲日派分子正积极活动，企图包围平津当局、动摇坚决抗战的方针。本文写于七月二十三日，要解决的是"抗战方针已经宣布之后应当怎么办"这一紧迫问题。按编者说明，文中所讲两种方针、两套办法、两个前途，正说明抗日战争中一条共产党路线和另一条蒋介石路线之间的斗争。

### 主要在解决什么问题
作者针对的不是要不要抗战的表态，而是几种现实危险：其一，妥协退让的方针仍在活动，如不迅速改变将使平津华北尽丧敌手；其二，即便宣布坚决抗战，若不随之以一整套相应办法，抗战仍不能胜利——六年不抵抗主义的教训表明，一切办法都反映着方针；其三，"精诚团结"这类口号只讲得好听、做不好看，打小算盘、阳奉阴违实际拆毁统一战线；其四，民族战争而不依靠人民大众必不能胜利，阿比西尼亚的覆辙可为前车之鉴；其五，人们普遍担心前途不明，需要说清前途由什么决定。

### 作者最后给出的答案
坚决抗战与妥协退让是两种根本矛盾的方针，必须坚持前者、反对后者。在坚决抗战方针之下必须有一整套办法才能达到目的，这套办法即八大纲领：全国军队总动员、全国人民总动员、改革政治机构、抗日的外交、改良人民生活、国防教育、抗日的财政经济政策、筑成民族统一战线的长城，其中心关键在国共两党亲密合作。"办法是跟着方针来的"，另有样样与之相反的第二套办法。两种方针、两套办法各自导向确定的前途：第一种得驱逐日寇、中国自由解放，第二种得日本占领中国、人民都做牛马奴隶。检验对坚决抗战是否有诚意，就看其肯不肯采取并实行这一套办法。

### 全文怎么推进
并列引用国共两党两个宣言、确认"坚决抗战、反对妥协退让"为第一种正确方针 → 指出汉奸亲日派活动使妥协退让成为第二种可能方针，二者根本矛盾，号召各方团结拥护坚决抗战 → 提出方针之下必须有一整套办法，逐项列出八大纲领，并把国共合作定为统一战线的中心关键 → 以"试验有无诚意，看他肯否采取并实行这一套办法"给出检验标准 → 逐条列出样样相反的第二套办法，说明"办法是跟着方针来的"，并以六年不抵抗主义的教训为证 → 由两种方针、两套办法推出两个确定的前途 → 结论落到实行第一种、争取第一个前途，反对第二种、避免第二个前途。

##### 02、为动员一切力量争取抗战胜利而斗争
### 为什么写
按编者说明，这是一九三七年八月二十五日为中共中央宣传部起草的关于形势与任务的宣传鼓动提纲，由八月二十二日至二十五日在陕北洛川召开的中共中央政治局扩大会议通过。此时卢沟桥事变已使全国性抗战开始，"九一八"以来中国统治当局的对日不抵抗政策开始转变为实行抗战，一二九运动以来的革命形势由停止内战准备抗战的阶段过渡到实行抗战的阶段。但日寇夺取平津后必将继续大规模进攻，察哈尔、上海的烽火已经燃烧起来。文章要为全党和全国说清这一阶段的形势判断与共同任务。

### 主要在解决什么问题
作者要处理的不是抗战已否开始，而是抗战怎样才能不失败：其一，如何看待国民党已经发生的转变——既不能否认其进步，也不能因进步而忽视其在发动民众和改革政治等问题上依然没有转变；其二，国民党对人民抗日运动基本上依然不肯开放、对政府机构不愿作原则的改变、对人民生活没有改良方针、对共产党关系未到真诚合作，如因循不改将使抗战蒙受绝大不利；其三，"待抗战胜利后再实行政治改革"这种主张，其根子是以为单纯的政府抗战便可以战胜日寇；其四，投降妥协的汉奸理论与以为无法战胜日寇的民族失败主义这两种相反的错误；其五，各方缺少一个可以共同执行的具体纲领。

### 作者最后给出的答案
今后的任务是"动员一切力量争取抗战胜利"，这里的关键是国民党政策的全部的和彻底的转变。单纯的政府抗战只能取得某些个别的胜利，要彻底地战胜日寇是不可能的；只有全面的民族抗战才能彻底地战胜日寇，而要实现全面的民族抗战，必须国民党政策有全部的和彻底的转变，必须全国上下共同实行一个彻底抗日的纲领。据此提出十大救国纲领：打倒日本帝国主义、全国军事的总动员、全国人民的总动员、改革政治机构、抗日的外交政策、战时的财政经济政策、改良人民生活、抗日的教育政策、肃清汉奸卖国贼亲日派巩固后方、抗日的民族团结。必须抛弃单纯政府抗战的方针，实现全面的民族抗战的方针；坚决反对投降妥协的汉奸理论，同时坚决反对民族失败主义。

### 全文怎么推进
（甲）先确认形势的积极一面：卢沟桥抗战是全国性抗战的开始，政策由不抵抗转变为实行抗战，肯定国民党的转变与前线军队的英勇抗战 → （乙）转到另一面：国民党当局又依然继续"九一八"以来的错误政策、压制爱国军队与人民救国运动，日寇必将坚持大规模进攻 → 援引东北平津丧失、阿比西尼亚亡国、苏联战胜外敌、西班牙保卫马德里四组先例，要求坚固团结、作战到底 → 提出今后任务是"动员一切力量争取抗战胜利"，关键在国民党政策全部彻底转变 → 驳"待抗战胜利后再实行政治改革"，区分单纯政府抗战与全面民族抗战 → （丙）提出十大救国纲领并逐项具体化为可执行条款 → （丁）结论：抛弃单纯政府抗战方针，实现全面民族抗战，同时反对汉奸理论与民族失败主义。

##### 03、反对自由主义
### 为什么写
本文写于一九三七年九月七日，即全面抗战开始、党和革命团体面临繁重战斗任务的时期（写作时间为版本标注，原文未附编者说明与注释，此处不另补史料）。写作任务由正文首尾自明：开篇提出"我们主张积极的思想斗争，因为它是达到党内和革命团体内的团结使之利于战斗的武器"，结尾把反对自由主义倾向列为"思想战线的任务之一"。所针对的直接问题是：自由主义取消思想斗争、主张无原则的和平，结果使腐朽庸俗的作风发生，使党和革命团体的某些组织和某些个人在政治上腐化起来。文章要使这种弥散而难以指认的倾向成为可以辨认和纠正的对象。

### 主要在解决什么问题
作者要解决的不是某一个人的具体错误，而是一种没有明确边界、人人都可能沾染却不易指认的倾向：因为是熟人同乡同学朋友便明知不对也不作原则争论；当面不说背后乱说；事不关己高高挂起；不服从命令只要照顾不要纪律；把争论变成个人攻击泄私愤；听了不正确甚至反革命的话也不报告；见群众不宣传不调查不关心；见损害群众利益的行为听之任之；办事不认真得过且过；摆老资格；自己错了也不想改正。这些表现分散在日常关系与工作之中，单靠定义或总体谴责无法处置。同时要解决的还有：一部分人赞成马克思主义却不准备实行，说的是马克思主义、行的是自由主义。

### 作者最后给出的答案
自由主义是一种腐蚀剂，使团结涣散、关系松懈、工作消极、意见分歧，使革命队伍失掉严密的组织和纪律，政策不能贯彻到底，党的组织和党所领导的群众发生隔离。它的来源在于小资产阶级的自私自利性，以个人利益放在第一位、革命利益放在第二位。它是机会主义的一种表现，和马克思主义根本冲突，客观上起着援助敌人的作用，革命队伍中不应该保留它的地位。克服的办法是用马克思主义的积极精神克服消极的自由主义：共产党员应襟怀坦白、忠实、积极，以革命利益为第一生命，以个人利益服从革命利益，无论何时何地坚持正确的原则，同一切不正确的思想和行为作不疲倦的斗争，关心党和群众比关心个人为重。最后号召忠诚坦白积极正直的党员团结起来，使有此倾向的人改变到正确的方面来。

### 全文怎么推进
先立标准：积极的思想斗争是达到团结、利于战斗的武器 → 指出自由主义取消思想斗争、主张无原则的和平，导致作风腐朽与政治腐化 → 把这一弥散倾向逐条落为十一种可对照的具体表现，并声明"还可以举出一些" → 说明它对组织造成的实际损害（涣散、失纪、政策不能贯彻、党群隔离） → 追溯其来源为小资产阶级的自私自利性 → 揭示其思想方法：以抽象的教条看待马克思主义原则，说的与行的、对人与对己两样货色齐备 → 判定其性质：机会主义的一种表现，客观上援助敌人，队伍中不应保留其地位 → 给出克服办法与共产党员的标准 → 落到团结正直党员、使有此倾向者改变过来这一思想战线任务。

##### 04、国共合作成立后的迫切任务
### 为什么写
一九三七年九月二十二日和二十三日，中国共产党为宣布两党合作成立的宣言与蒋介石承认共产党合法地位的谈话，经国民党中央通讯社先后发表，两党统一战线宣告成立。本文写于九月二十九日，正是这一节点之后。作者在文中自述了这一过程的来龙去脉：一九三三年提出三条件下与任何国民党部队订立抗日协定的宣言、一九三五年八月的号召与十二月的决议、一九三六年五月通电、八月致国民党中央委员会的信、九月建立统一的民主共和国的决议，直到西安事变和平解决、今年二月国民党三中全会前夜的五项四项建议、红军改名为国民革命军第八路军。文章要回答的是：统一战线既已成立，接下来最迫切的任务是什么。

### 主要在解决什么问题
作者针对的是"合作已经成立"之后被忽略的几件事：其一，现在成立的统一战线还不是一个充实的坚固的统一战线，事实上还停止在两个党的范围之内，广大的工人、农民、兵士、城市小资产阶级及其他爱国同胞还没有被唤起、发动、组织和武装，这是目前最严重的情形，直接影响到前线不能打胜仗；其二，起了变化的只是停止内战、一致抗日，而政府机构、军队制度、民众政策以及财政、经济、教育等项政策大体上还是十年来的一套，"没有变化的东西和变化了的东西不相适应"；其三，还没有一个为两党共同承认和正式公布的政治纲领去代替国民党的统制政策；其四，有人以为共产主义和三民主义不能并存，因而怀疑共产党愿意实行三民主义的诚意；其五，即使有了纲领，也还缺少能够执行它的政府和军队。

### 作者最后给出的答案
统一战线必须由两党范围扩展为全民族的统一战线，挽救前线危机的唯一道路是实行孙中山"唤起民众"的遗嘱，统制、镇压与这一原则相违背，单纯的政府和军队的抗战决然不能战胜日本帝国主义。要使统一战线坚固，须有一个共同纲领：它既是行动方针，也是一种约束，像一条绳索把加入统一战线的各方紧紧约束起来，以新的约束代替旧的那一套，建立革命秩序。共同纲领就是孙中山的三民主义和共产党八月二十五日提出的抗日救国十大纲领。共产主义与三民主义并非不能并存：共产主义在将来阶段实行，现阶段实行的是历史规定的民族革命主义和民主革命主义；而共产党十年来的政策实质上正合于三民主义——反帝即彻底的民族主义，工农民主专政即彻底的民权主义，土地革命即彻底的民生主义。最后，实行纲领需要工具，因此必须改造政府（建立民族民主的统一战线的政府）和改造军队（实行官兵一致、军民一致，一面打仗一面改造，中心任务是改变军队的政治精神和政治工作）。

### 全文怎么推进
先回顾从一九三三年到一九三七年九月两党关系的全过程，确认统一战线已经成立并评价蒋介石谈话的可取与不足 → 以一九二四至一九二七年合作的成就与破裂后的失败，说明两党关系对中国革命起决定作用 → 列举统一战线已经产生的四个证据，同时逐条指出其不足 → 断定现在的统一战线还不充实、不坚固 → 指出统一战线不限于两党而是全民族的，民众未被唤起是最严重的情形，挽救危机的唯一道路是"唤起民众" → 指出没有变化的东西和变化了的东西不相适应，需要共同纲领作为新的约束 → 说明共同纲领即三民主义与十大纲领，并以阶段区分和实质对照解除"两个主义不能并存"的疑问 → 提出实行纲领需要工具，因而必须改造政府和改造军队 → 向国民党抗日同志提出建议并作结。

##### 05、和英国记者贝特兰的谈话
### 为什么写
一九三七年十月二十五日，毛泽东与英国记者贝特兰的谈话。此时全面抗战已爆发三月有余，中共的抗战主张、八路军的实际情形、投降主义的危险与"民主"的含义，都是外界迫切想了解的。谈话以一问一答的方式，系统说明了中国共产党在抗日战争中的立场、八路军的作战与政治工作、对投降主义的判断，以及所主张的民主制度，既是对外的政策宣示，也是对内统一认识的回答。

### 主要在解决什么问题
谈话针对的是外界对四个方面的疑问：其一，中国共产党在中日战争中的具体主张是什么，抗战的成绩与教训何在；其二，八路军究竟如何作战、它的政治工作有何特殊；其三，日本一面作战一面放"和平空气"是什么企图，投降主义危险如何克服；其四，纲领中的"民主"与"战时政府"是否冲突，"民主集中"在名词上是否自相矛盾。问题背后是：一个外人和许多旁观者仍看不清这场战争的性质、走向与中共方案的根据。

### 作者最后给出的答案
共产党的基本口号是"全面的全民族的抗战"，其政策集中体现为抗日救国十大纲领，它符合孙中山三民主义、三大政策及其遗嘱的精神。八路军以独立自主的游击战和运动战为主，以政治工作的三原则（官兵一致、军民一致、瓦解敌军和宽待俘虏）保证战斗力。投降主义根源于民族失败主义，须言论上指出、行动上组织群众制止，群众克服它则战线巩固。民主制度即排除汉奸卖国贼外一切抗日阶级联盟的民主共和国，其组织形式是民主集中制——民主与集中并不冲突，正义的人民战争正需要它。新的政治制度之实现，关键在于国共两党在共同纲领上的彻底合作。

### 全文怎么推进
先由"中国共产党和抗日战争"答复中共的具体表示、抗战已产生的两面结果与五项成绩、片面抗战的教训，并引出十大纲领与三民主义共同纲领 → 再由"在抗日战争中的八路军"说明战斗情况、独立自主的游击战和运动战、政治工作三原则，并以一九二四至一九二七年先例证明这些长处可适用于其他中国军队 → 继而"抗日战争中的投降主义"识破日本和平烟幕的三个目的，指出两种前途，给出克服之道（失败中辨胜利因素、组织群众）→ 最后"民主制度和抗日战争"以"不但看名词更看实际"判别民主集中制，援引两类战时政治制度先例，说明实现新政制的步骤在于国共合作与召集临时国民大会。

##### 06、上海太原失陷以后抗日战争的形势和任务
### 为什么写
一九三七年十一月十二日，毛泽东在延安中国共产党的活动分子会议上作报告提纲。上海、太原相继失陷，抗战进入一个新节点；从这时起，党内右倾机会主义分子就反对这个提纲，直到六届六中全会才基本克服这种右的偏向。本文要回答的是：失陷之后形势究竟怎样、任务应是什么，以及党内党外必须反对什么样的危险。

### 主要在解决什么问题

##### 07、陕甘宁边区政府第八路军后方留守处布告
### 为什么写

据编者说明，这个布告是毛泽东为陕甘宁边区政府和八路军后方留守处起草的，目的是对付蒋介石集团的破坏活动。当时国共合作成立不久，蒋介石集团即阴谋破坏共产党领导的革命力量，破坏陕甘宁边区是这种阴谋的一部分；毛泽东认为为了保护革命的利益，必须采取坚定的立场。编者同时指出，这个布告打击了当时共产党内一部分同志在抗日统一战线中对于蒋介石集团的阴谋活动所采取的机会主义立场。据注释，陕甘宁边区由刘志丹、谢子长等在陕甘边和陕北领导游击战争建立的根据地发展而来，一九三七年抗日民族统一战线建立后由陕甘宁革命根据地改名，共辖二十三个县；边区大部分地方原已实行没收地主土地分给农民并废除农民原负债务，一九三六年决定停止没收开明绅士的土地，一九三七年又宣布以减租减息代替没收，同时宣布坚决保障农民已从土地改革中获得的果实。文中援引的《抗战建国纲领》为一九三八年三、四月间国民党临时全国代表大会所制定。

### 作者最后给出的答案

先确认共同前提：全国爱国同胞坚决抗战、各党各派精诚团结是"中华民族的光明大道，抗日胜利的坚强保障"，凡属国人必须循此前进 → 把本区放入这一前提之下，说明边区军民服从政府领导、凡所实施光明正大、全国人民交口称誉，本府本处惟有激励民众继续努力 → 以"乃近查边区境内"转折，逐项列举强迫退地退债、强迫改变民主制度、破坏各类组织，直至充当暗探、联络土匪、煽动哗变、测绘地图 → 按共同原则定性：显系违反团结抗日的基本原则、违反边区人民的公意，企图制造内部纠纷、破坏统一战线、破坏人民利益、破坏边区政府威信、增加抗日动员的困难 → 追究原因为少数顽固分子恣意妄为，甚有为日寇所利用、假借名义作为掩护 → 以各县人民"日必数起"的请求为依据，提出为增强抗日力量、巩固抗日后方、保护人民利益起见"不得不实行取缔" → 落到四条具体规定：保护既得成果、保护既有组织、外来人员凭证准入、群众告发与讯实严惩 → 以效力声明作结。

##### 08、抗日游击战争的战略问题
### 为什么写

据编者说明，抗日战争初期，中国共产党内和党外都有许多人轻视游击战争的重大战略作用，而只把自己的希望寄托于正规战争，特别是国民党军队的作战；毛泽东批驳了这种观点，同时写了这篇文章，指出抗日游击战争发展的正确道路。编者并交代了其结果：在抗日时期内，一九三七年只有四万余人的八路军和新四军，到一九四五年日本投降时发展成为一百多万人的大军，创建了许多革命根据地，使蒋介石在抗日时期既不敢投降日本，又不敢发动全国规模的内战。文章写于一九三八年五月，文中所举五台山、太行山、泰山、燕山、茅山等根据地，据注释均为一九三七年冬至一九三八年间由八路军、新四军依托山区开辟或正在开辟之中；文中对平原能否建立长期根据地留有存疑，注释指出后来的经验证明平原地区能够建立长期的、许多地方并能成为固定的根据地。

### 主要在解决什么问题

要解决的是把游击战争只当作战术问题的看法。作者承认"抗日战争中，正规战争是主要的，游击战争是辅助的"，问题在于：辅助地位是否就意味着它只有战术问题。与此相连的是一系列具体的错误认识与做法——不要或不重视根据地的流寇主义思想；只知发展而忘记巩固的保守主义与其反面；把正规战争的高度集中指挥方法搬到游击战争上，或者相反地要求绝对分散；集中小部队时只顾地方利益的地方主义与只图扩充自己的单纯军事主义；以及在敌人数路围攻面前因估计不足而惊惶失措、在敌人转取守势时得意忘形。此外还须避免另一种简单化：既然游击战争与整个抗日战争的战略问题许多东西一致，就把一般战略问题中的东西照样用之于游击战争。

### 作者最后给出的答案

游击战争虽仍处于辅助地位，但必须放在战略观点上加以考察，因为中国是大而弱的国家被小而强的国家攻击而又处于进步的时代，由此产生敌占地甚广、战争长期、在外线单独作战、规模巨大等条件，于是战略防御、战略进攻、根据地、向运动战发展等成套问题都发生了。一切军事行动的根据是保存自己、消灭敌人，游击战争还须加上发展自己。据此提出六项战略纲领：主动地、灵活地、有计划地执行防御战中的进攻战、持久战中的速决战、内线作战中的外线作战；和正规战争相配合；建立根据地；战略防御和战略进攻；向运动战发展；正确的指挥关系。主动权由正确的情况估计和正确的处置产生，靠抓住对方兵力不足、异国作战、指挥笨拙三个弱点取得；灵活性表现为分散、集中、转移三种兵力使用方法的及时变换；根据地须靠建立武装部队、战胜敌人、发动民众三个条件逐步造成；指挥上采取"战略统一下的独立自主的游击战争"。

### 全文怎么推进

先承认游击战争在整个抗日战争中是辅助的，随即以反设条件的方式追问它为什么仍有战略问题——若为小国、若如苏联那样强大，它就只有战术问题 → 列出中国的实际条件：大而弱的国家被小而强的国家攻击而处于进步的时代，由此产生占地甚广、战争长期、外线单独作战、规模巨大，于是成套的战略问题发生，同时限定一般战略问题的东西不能照搬 → 退回到更基本处，把一切军事行动的根据确立为保存自己、消灭敌人，并说明牺牲与保存相反相成 → 由此提出六项战略纲领 → 展开第一项：在战略的防御、持久、内线之下取战役战斗的进攻、速决、外线，并说明许多局部胜利的集合才达到总体目的；再依次说明主动性、灵活性、计划性 → 第二项按战略、战役、战斗三个层级分别规定配合的责任 → 第三项由战争的长期性与残酷性推出根据地的必要，驱除流寇主义，区分三种地形、区分游击区与根据地、给出三个基本条件，并以敌我几种包围和围棋"做眼"说明根据地的战略作用 → 第四项按敌之攻守姿势分别给出反围攻与扩大充实的方针 → 第五项说明向运动战发展的两个条件与两种相反错误 → 第六项以情况能否为上级掌握划定集中与分散的界限，落到"战略统一下的独立自主的游击战争"。

##### 09、论持久战
### 为什么写

一九三八年五月，抗战已进行十个月，但"持久战"在国内外并未真正被理解和接受：一面是"中国必亡"的亡国论在暗地流行，另一面是"很快就能战胜"的速胜论在胜仗之后抬头。作者在全民族团结抗战一周年前夕，应许多人要求作一次总结性的解释，既击破亡国论、说服速胜论，也为全党研究持久战提供系统的根据。

### 主要在解决什么问题

文章要解决的不是战术细节，而是两个相互缠绕的认识错误：其一是亡国论，只抓住敌强我弱一个因素夸大成全部论据，看不到时代、进步与多助；其二是速胜论，忘记或抹杀敌强我弱，夸大长处、拿一时一地的强弱现象代替全体。二者共同的病根是主观性、片面性——用单一因素或一时现象代替全部基本因素的相互关系。文章还要回答：既然是持久战，怎样具体进行才能争取最后胜利。

### 作者最后给出的答案

结论是：中国不会亡，抗日战争是持久战，最后胜利是中国的。根据在于中日双方全部互相对立的基本特点——敌强而我弱、敌小我大、敌退步野蛮我进步正义、敌寡助我多助；这些特点的比赛规定战争是持久而结局属我。进行持久战的具体道路是三阶段（防御—相持—反攻），在战略内线持久防御之下以战役战斗的外线速决进攻战改变总体态势，靠政治动员把民众变为伟力之本，并避免战略决战、以空间换时间，等待反攻。

### 全文怎么推进

文章沿"提出问题—摆根据—破错误—立结论—讲做法"推进：①从抗战十个月经验提出亡国论与速胜论两种错误（P4–P8）；②用"全部基本因素的相互关系"这一方法说明为什么是持久战（P9、P23、P32–P36）；③以时代特点驳亡国论、以全面因素驳速胜论，确立"不悲观、不空谈"的立场（P38–P57）；④把持久战分解为三阶段并说明各阶段作战形式（P65–P75）；⑤转入"怎样做"：从能动性、战争与政治、政治动员、战争目的，到防御中进攻、持久中速决、内线中外线（P92–P114）；⑥展开主动性、灵活性、计划性，运动战游击战阵地战，消耗战歼灭战（P116–P138）；⑦讲乘敌之隙、决战问题、兵民是胜利之本，归结于普遍深入的政治动员（P153–P162）。

##### 10、中国共产党在民族战争中的地位
### 为什么写

一九三八年十月，党的六届六中全会批准了以毛泽东为首的中央政治局路线，确定坚持抗日民族统一战线、批判统一战线中的迁就主义、确定党的工作方面在战区和敌后。毛泽东在报告中专设"中国共产党在民族战争中的地位"一节，意在使全党明确并认真负起领导抗日战争的重大历史责任——即共产党员应如何认识、加强、团结自己，才能领导战争达于胜利。

### 主要在解决什么问题

文章要解决的是党内与统一战线中的一系列工作方法与倾向问题：怎样把国际主义与爱国主义统一而不脱节；怎样既坚持统一战线又不被取消独立性；怎样处理阶级斗争与民族斗争的关系；怎样识别、使用、爱护干部；怎样在反对一种错误倾向时不走到另一种极端；怎样把马克思主义变成中国自己的东西而不当教条。其共同隐患是"只顾一方面，忘记另一方面"的片面性。

### 作者最后给出的答案

核心判断是：中国共产党必须在民族战争中成为坚强的核心，以自身的团结与方法领导胜利。具体答案是一组相对应成的方法——以爱国主义实施国际主义；在统一战线中保持相对独立性；照顾全局、多数并与同盟者共事；把马克思主义与中国特点结合；以全部历史识别干部、以指导检查培养干部；大胆发展党又防奸细；在两条战线斗争中同时反右与反左且切合对象；扩大民主又守纪律。内部团结是团结全国人民争取胜利的最基本条件。

### 全文怎么推进

文章以"党处于何种地位"的问题起（P3），先解决立场：国际主义与爱国主义在具体历史条件下统一（P5）；再讲党员模范作用（P7）；转入对敌与对内的两面对：团结全民族又反对奸细、扩大党又防奸细混入（P9、P11）；讲统战中的统一与独立、阶级与民族斗争的调节（P13、P14）；讲领导方法：照顾全局多数与同盟者共事、干部政策、纪律、民主（P16–P28）；用两条战线斗争的历史总结党如何从斗争中巩固（P30–P34）；落到当前仍须同时反两种倾向且切合对象（P36–P38）；最后讲学习（马克思主义中国化）与团结胜利（P40–P46）。

##### 11、统一战线中的独立自主问题
### 为什么写

这是六届六中全会毛泽东结论的一部分（一九三八年十一月五日），针对当时与陈绍禹在抗日民族统一战线问题上的突出分歧——本质上即统一战线中无产阶级领导权问题。文章要澄清：统一战线中的"独立自主"不是分裂合作，而是使合作不被混一、不被自我束缚地落到实处。

### 主要在解决什么问题

文章针对两种偏向：一是把互助互让看成纯消极的让步，乃至重犯陈独秀、张国焘式的投降主义；二是在"一切经过统一战线"的口号下把自己手脚捆住，对国民党一味事前请示、不敢放手。核心问题是：在合作中如何既维持统一、又不放弃党派与阶级的必要权利与独立自主。

### 作者最后给出的答案

答案是"既统一，又独立"。互助互让必须是积极的——让步、退守、防御都当作整个革命政策的一环、曲线运动的一个片断，用以达到积极目的（有所不为而后可以有为）。民族斗争与阶级斗争在"抗日"这一根本原则下一致，阶级要求以不破裂合作为条件、以民族需要为出发点。对"一切经过统一战线"必须拒绝，改为按事项与对方态度分四类灵活处置，但不破裂统一战线。

### 全文怎么推进

文章从互助互让应积极起（P4）：用"让了前者得后者""为了更好一跃而后退"说明让步是积极环节；再讲民族斗争与阶级斗争的一致性（P6）：在抗日根本原则下保存党派阶级独立性，使统一与独立、民族与阶级一致；最后落到"一切经过统一战线"不对（P8）：按事项分先奏后斩、先斩后奏、斩而不奏、不斩不奏四类，底线是不破裂统一战线又决不自我束缚。

##### 12、战争和战略问题
### 为什么写

这是六届六中全会毛泽东结论的一部分（一九三八年十一月六日）。犯右倾机会主义错误的同志否认统一战线中的独立自主，因而对党在战争和战略问题上的方针也怀疑反对。文章从中国政治斗争历史着重说明战争和战略问题在中国革命中的首要地位，打通全党在领导思想与工作上的一致。

### 主要在解决什么问题

文章要解决的是党内对"战争和战略"的轻视与认识不足：一是不懂得武装斗争在中国的极端重要性，片面着重民众运动；二是照搬外国（资本主义各国）的"长期合法斗争、先城市后乡村"经验，不顾中国半殖民地半封建、无议会无合法权利的特点；三是在军事战略转变中发生两种偏差——不愿向正规性转变的右倾与机械搬外国经验的"左"倾。核心问题是中国革命的主要斗争形式与组织形式是什么、战略如何随战争过程转变。

### 作者最后给出的答案

答案是：武装夺取政权是普遍原则，但中国必须走与资本主义国家相反的的道路——以战争为主要斗争形式、以军队为主要组织形式，离开了武装斗争就没有党和无产阶级的地位。全党都要注重战争、学习军事。军事战略要随国内战争与民族战争两个过程、四个战略时期作三个转变，每次转变同时防两种偏差；在战争全体上正规战为主、游击战为辅，但游击战争占极重要战略地位。原则是党指挥枪，而非枪指挥党。

### 全文怎么推进

文章从普遍原则与本国条件对比起（P4–P8）：资本主义国走合法斗争、先城市后乡村，中国因无议会受内外压迫而走相反道路，主要斗争形式是战争、组织形式是军队（P4、P6、P8）。接着以国民党与共产党战争史说明"有军则有权""枪杆子出政权"但须党指挥枪（P14、P15、P21）。再讲军事战略的三个转变及每次的两种偏差（P28–P32）。然后定位游击战争：全体上正规为主、游击为辅，但战略地位极重要（P35、P36）。最后呼吁把战争战略理论作骨干、研究并通俗化（P41）。

##### 13、五四运动
### 为什么写
一九三九年五月一日作。据编者说明，这是为延安出版的中共中央机关报《解放》写的纪念五四运动二十周年的文章。此时距五四运动已整二十年，抗日战争也快到两周年。抗战爆发后大批青年学生和文化界人士涌入救亡运动，五四纪念因此不只是历史评价问题，也是当下的方向问题：二十年前那场以数十万学生为先头的运动究竟属于什么性质，今天的抗日战争在整个中国革命过程中处在哪一步，青年和文化界应当把自己放到什么位置上去。作者借纪念之机把五四放回中国资产阶级民主革命的全过程中定位，并由此对青年提出要求。

### 主要在解决什么问题
要解决的首先是孤立地看待革命事件的认识：把五四仅仅当作一次文化革新运动，或把鸦片战争以来各次革命看成彼此无关的片段，于是既说不清五四比辛亥革命进步在哪里，也说不清今天的抗战处在什么阶段、要到哪里才算成功。其次是革命依靠谁、由谁领导的问题——如果离开工农这一根本力量和工人阶级的领导，反帝反封建的民主革命不可能完成。再次是知识分子的自我定位问题：知识分子在民主革命中首先觉悟，容易以自己口讲的主义自居革命者，而不去和工农民众结合。作者要回答的是：判定一个知识分子革命与否，究竟用什么标准。

### 作者最后给出的答案
五四运动表现中国反帝反封建的资产阶级民主革命已经发展到一个新阶段，它成为文化革新运动只是这一民主革命的一种表现形式；它比辛亥革命进了一步，在于新的社会力量生长出一个壮大了的阵营——工人阶级、学生群众和新兴的民族资产阶级，而数十万学生英勇地出现于运动先头。从鸦片战争起，经太平天国、甲午战争、戊戌维新、义和团、辛亥革命、五四、北伐、土地革命战争，到今天的抗日战争，各阶段各有特点，其中最重要的区别在共产党出现以前及其以后，但就全体看来无一不带资产阶级民主革命性质；直到帝国主义势力和封建势力基本被推翻、建立独立的民主国家，才算这一革命成功。革命依靠革命的工、农、兵、学、商，根本的革命力量是工农，领导阶级是工人阶级。知识分子革命与否的最后分界，仅仅在是否愿意并且实行和工农民众相结合，而不在乎口讲什么三民主义或马克思主义。据此要求全国青年和文化界到工农民众中去，变为他们的宣传者和组织者。

### 全文怎么推进
判定五四运动的性质：它是资产阶级民主革命发展到新阶段的表现，文化革新只是其表现形式 → 指出它比辛亥革命进步之处在于阵营壮大、数十万学生走在先头 → 把五四放回从鸦片战争到抗日战争的完整阶段序列，指明各阶段的最重要区别与共同性质，并给出革命成功的终点与社会制度的前身后身 → 由性质转到动力：列出所依靠的社会势力，在其中区分根本的革命力量与领导阶级，并指明当前的根本敌人、根本政策和胜利条件 → 转到知识分子：承认其首先觉悟，随即给出唯一的最后分界——是否和工农民众相结合 → 落到当下，要求全国青年和文化界认识革命的性质和动力，到工农民众中去，做工农民众的宣传者和组织者。

##### 14、青年运动的方向
### 为什么写
一九三九年五月四日作。据编者说明，这是在延安青年群众举行的五四运动二十周年纪念会上的讲演，作者在讲演中发展了关于中国革命问题的思想。据注释，同年三月陕甘宁边区的青年组织规定以五月四日为中国青年节，国民党在广大青年爱国高潮的压力下也一度同意（后因畏惧青年学习"五四"的革命精神，又改定三月二十九日为青年节，而根据地内继续沿用五月四日）。其时抗日战争已近两年，各地以至海外的大批革命青年来到延安求学，三天前作者刚为《解放》写了《五四运动》一文。讲演要回答的是全国青年运动往哪个方向走。

### 主要在解决什么问题
要解决的是一串互相连着的问题：五四那样反对政府的运动凭什么算革命；今天这个革命的对象、主体、动力、性质和目的到底是什么，做到哪一步为止；几十年革命为什么只得到暂时的部分的胜利；青年在整个革命力量中处在什么位置，单靠知识青年和学生青年能不能取胜；判断一个青年是不是革命的用什么标准，嘴上大讲三民主义或马克思主义算不算数；青年运动不统一怎么办；延安的做法凭什么可以当全国的模范。这些问题共同针对的现实倾向是：过去几十年的青年运动中，有一部分青年不愿意和工农大众相联合，甚至反对工农运动。

### 作者最后给出的答案
定五四为青年节，表示反帝反封建的人民民主革命快要进到由失败转向胜利的转变点，但转变还没有到来，须在抗日战争中争取。五四反对的是勾结帝国主义、出卖民族利益、压迫人民的卖国政府，所以它是革命的运动；孙中山反清同理。现在的革命对象是日本帝国主义和汉奸，主体是中国的老百姓，动力包括无产阶级、农民阶级和其他阶级中一切愿意反帝反封建的人，根本力量是占全国人口百分之九十的工农，性质是资产阶级性的民主主义革命——不超出这个范围，不破坏一般资产阶级的私有财产制，目的是建立人民民主的共和国，它既不同于半殖民地半封建的现状，也不同于将来不要资本家的社会主义制度。几十年革命未成的原因是敌强己弱，而己弱的主要方面是占人口九成的工农劳动群众还没有动员起来，教训根本就是"唤起民众"这一条。青年是重要的方面军而不是主力军，主力军是工农大众，所以知识青年和学生青年一定要到工农群众中去，和他们结合成一体。判断青年革命与否只有一个标准，就是看他愿意不愿意、并且实行不实行和广大工农群众结合，口讲什么主义都不算数。延安青年运动政治方向正确、工作方法也正确，所以是全国青年运动的模范。

### 全文怎么推进
从青年节的设立讲起，判定它标志着人民民主革命快要进到由失败转向胜利的转变点，并借"该不该反对卖国政府"确认五四的革命性质 → 转入当前革命本身，成套地回答对象、主体、动力、根本力量、性质、目的，并用与半殖民地半封建现状、与将来社会主义制度的双向差别划出边界 → 回顾五十年至一百年的斗争史，判定只有暂时的部分的胜利，把原因收敛为敌强己弱，再把己弱的主要方面定在工农群众尚未动员，归结为"唤起民众"一条道理 → 由此确定青年的位置：起先锋队作用、是重要的方面军，但不是主力军，必须与工农主力结合，并据此把不愿与工农联合的倾向判为逆流，重申唯一的判别标准并用自称与实际背离的反例加以说明 → 指出抗日战争是革命的新阶段，人民和青年的进步是这次能由失败转向胜利的根据，并要求青年运动实行统一 → 以延安青年运动为例，用团结统一、与工农结合、学理论、搞生产四项同旧学塾与全国其他学校对照，归结为政治方向和工作方法都正确，故可为全国模范 → 结语要求研究五十年革命经验，使全国青年和人民结合、组织、团结起来。

##### 15、反对投降活动
### 为什么写
一九三九年六月三十日作。据编者说明，这是为纪念抗日战争两周年写的文章。据注释，武汉、广州失陷后日本改取诱蒋投降为主的方针，一九三八年十一月的声明宣称只要国民政府"改弦易辙"、参加"新秩序"建设，日方"亦不拒绝"；与此同时，英美帝国主义在一九三八、一九三九年间几次酝酿出卖中国以换取对日妥协，作者写此文时英日正在谈判，这一阴谋被称为"东方慕尼黑"，国内则有召开所谓太平洋国际会议的鼓吹。又据注释，一九三九年一月蒋介石在国民党五届五中全会上把"抗战到底"的"底"说成恢复卢沟桥事变以前的状态。汪精卫已公开投敌，抗日阵线内部的动摇更加严重。文章即针对这一形势而作。

### 主要在解决什么问题
要解决的是"和战问题"重新抬头带来的认识混乱：卢沟桥的炮声既已宣告"战则存"是对的，为什么争论又起，换了名目的争论算不算新问题；主和派为什么一开口先反共，反共与投降之间到底是什么关系；日本"已经不行了"、将自动退出华中华南甚至华北的说法能不能信；各大国出面对日本压一压、召开太平洋会议是不是有益于中国，算不算东方慕尼黑；抗战两年后各种困难并列，其中哪一项才是当前政治形势中的主要危险。文章要回答的是全国一切爱国党派和爱国同胞的当前紧急任务究竟是什么。

### 作者最后给出的答案
"战不战"改成"和战"，只是换了词句，双方论点依旧，性质还是一样，仍是一切问题中的第一个大问题、最根本的问题；它当初只被暂时解决，是由于日本的诱降政策、国际投降主义者的妥协企图和抗日阵线中一部分人的动摇性。主战派是全民族的大多数，主和派只是抗日阵线中一部分动摇分子，因此它不得不进行欺骗宣传，并成批制造假消息、假报告、假文件、假决议；它第一就反共，是因为共产党是抗日民族统一战线的发起者和坚持者，不反共就不能破坏国共合作、不能分裂统一战线、也就不能投降。日本帝国主义灭亡中国的根本方针决不会变，武汉失陷后的甜言蜜语是"诱鱼上钓取而烹之"的阴险政策；国际投降主义者纵容日本、坐山观虎斗，等时机一到就策动太平洋调停会议以收渔人之利，所谓太平洋会议就是东方慕尼黑，就是准备把中国变成捷克。当前形势的主要特点是：投降是主要危险，反共即准备投降。故当前紧急任务是反对投降和分裂——战下去、团结下去，中国必存；和下去、分裂下去，中国必亡。

### 全文怎么推进
从"战不战"这个历来劈头第一个大问题讲起，摆出两派相反的结论，指出卢沟桥的炮声只是暂时地解决了它，并列出未能最后解决的三条原因 → 指出问题已改换词句为"和战问题"重新提出，而两派论点依旧，据此判定为同一问题 → 比较两派的人数构成，由主和派只是一部分动摇分子推出它必须进行欺骗宣传，并沿必要条件链说明它为什么第一就反共，再列出它寄希望于日本让步和国际压力的两项打算，指认公开的与暗藏的两类推行者 → 公开宣布共产党的立场，逐条斥责分裂阴谋、太平洋会议的辩解和日本会让步的空谈，按根本方针判定敌方示好与第三方调停的性质 → 回到形势判断，重申问题性质未变，指出半年来三项变化中主要是内部动摇加剧，据此判定投降是主要危险、反共是准备投降的首要步骤 → 用两句对偶给出后果并要求国人速择，最后把当前紧急任务定为反对投降和分裂。

##### 16、必须制裁反动派
### 为什么写
一九三九年八月一日作。据编者说明，这是在延安人民追悼平江惨案死难烈士大会上的演说。据注释，同年六月十二日，国民党第二十七集团军派兵包围新四军驻湖南平江嘉义镇的通讯处，惨杀新四军参议涂正坤、八路军少校副官罗梓铭等六人，激起各抗日根据地人民和国民党统治区正义人士的公愤。其时武汉失守后日本对国民党已改取政治诱降为主的方针，英美也不断劝其同日本"议和"，一九三九年七月英日达成协议、英国承认日本侵华造成的"实际局势"；同年春国民党中央又秘密颁布《防制异党活动办法》等文件，规定用限制思想言论行动、建立特务通讯网等办法对付共产党人和进步分子。惨案发生近两个月而无人过问，演说即在此情形下发表。

### 主要在解决什么问题
要解决的是：在抗战两年、敌我尚未分胜负的时候，为什么被杀的不是汉奸而是最坚决的抗日分子，这件事该记在谁的账上；杀人已近两个月而法律和法官始终不出面，这说明了什么；对方以"统一"的名义压制共产党，这个名义要不要接受，如果接受又该怎样判断眼下究竟统一了没有；秘密颁行的《限制异党活动办法》把共产党列为"异党"加以限制，这里的"异党"和"限制"到底应当指谁。这些问题共同针对的现实是：一部分人身在抗日的大团结里面，却在杀抗日分子、压制进步、勾结日寇汉奸、准备投降。

### 作者最后给出的答案
杀人的是军队，军队是执行命令，指使者是反动派；而按常理要杀抗日战士的本是日本帝国主义和汪精卫等汉奸，事情却发生在抗战的后方平江而非日寇汉奸占领的地方，被杀的是新四军通讯处的负责同志——可见是中国反动派接受了日本帝国主义和汪精卫的命令来杀人，他们准备投降，所以先把最坚决的抗日分子杀死。惨案近两个月无人过问，本应过问的法律和法官始终不出面，而同样的事在陕甘宁边区高等法院早就过问了，缘故就是中国不统一。统一应予坚持——不统一就不能胜利——但统一的内容是大家抗日、大家团结、大家进步，要有赏有罚：赏抗日的、团结的、进步的人，罚破坏抗日团结进步的汉奸和反动派。以此逐项检验，抗日、赞成团结、进步的同志反被惨杀，破坏者未受一点处罚，可见应该统一的没有统一。同理，"异党"应指日本帝国主义、汪精卫和汉奸，"限制"应限制日寇、汪精卫、反动派和投降分子，而不是限制最抗日最革命最进步的共产党。故必须要求国民政府严办反动派，取消《限制异党活动办法》，制裁投降派、反动派，保护一切革命的、抗日的同志和人民。

### 全文怎么推进
从追悼会的缘由入手，逐层追问动手者、指使者，再用"按理该谁杀"与"实际杀在哪里、杀了谁"的错位，判定这是中国反动派接受日寇和汪精卫的命令而为、是准备投降的第一步 → 指出这类人就处在全国抗日的大团结内部，其所为是杀抗日分子、压制进步、勾结日寇汉奸 → 转而追查本应发生的反应：从六月十二日到八月一日无人过问，本该过问的法律和法官不出面，而同样的事在陕甘宁边区早被高等法院过问，据此把原因定在"中国不统一" → 接过"统一"这一名义并重新界定其内容：统一即抗日、团结、进步，落实为有赏有罚，再以赏罚事实逐项检验三项，得出"应该统一的没有统一"，并指出方向是落后向进步看齐 → 由个案上升到形势：日寇捣乱加紧、国际帝国主义助日更积极、公开与暗藏的汉奸破坏更积极，秘密办法《限制异党活动办法》即其根源 → 按同一办法拆解对方的关键用语，重派"异党"与"限制"的所指 → 落到三项要求：取消该办法、制裁投降派反动派、保护抗日的同志和人民。

##### 17、关于国际新形势对新华日报⑴记者的谈话
### 为什么写
一九三九年九月一日答《新华日报》记者问。据注释，《新华日报》是中国共产党在国民党统治区公开出版的机关报。此前八月二十三日苏德互不侵犯条约订立，而英法苏三国谈判自四月十五日进行到八月二十三日、历时四个多月归于破裂。据注释，英法政府近年一贯以"不干涉"政策纵容德意日侵略，先后有半个中国被牺牲给日本，阿比西尼亚、西班牙、奥国、捷克被牺牲给德意，一九三八年九月的慕尼黑协定是这一政策的顶点；同年九月德国法西斯首先向英法及其同盟国发动了战争。国内则对苏德协定与英法苏谈判破裂的因果关系存在倒置的理解，同时日本诱降与英国酝酿的远东慕尼黑正加重投降与分裂的危险。作者借答记者问系统估计国际新形势，并据以确定中国的前途与任务。

### 主要在解决什么问题
要解决的是一连串被误解或被回避的判断：苏德互不侵犯协定究竟意味着什么，它是不是英法苏谈判破裂的原因（人们把因果弄反了）；英法苏谈判为什么没有成功，责任在谁；欧洲两大帝国主义集团即将开战，双方都自称正义，这场战争到底算不算正义；美国这个第三集团会怎么动；日本受苏德协定打击后，它的目的会不会改变，进攻方式会怎样转移；中国已经走到哪个阶段，接下来的总任务是什么。这些问题共同指向的现实危险是：中国大部投降和内部分裂的可能正在加大。

### 作者最后给出的答案
苏德协定是苏联力量增长和坚持和平政策的结果，它打破了挑动苏德战争的阴谋和德意日集团对苏联的包围，在东方则打击日本、援助中国、增强中国抗战派、打击中国投降派。英法苏谈判破裂完全由于英法政府没有诚意：它们始终不赞成平等互惠原则，只要苏联保证其安全而不肯保证苏联和波罗的海诸小国的安全，以便开一个缺口让德国进兵；"不干涉"政策就是"坐山观虎斗"的损人利己政策，从张伯伦上台开始，到慕尼黑协定达到顶点，到此次谈判最后破产，其必然结果是"搬起石头打自己的脚"，以损人的目的开始、以害己的结果告终。第二次帝国主义战争已进到新阶段，欧洲将由一方进攻一方坐视的片面性状态转为全面战争；交战双方都会自称正义，但双方目的都是争夺对殖民地半殖民地和势力范围的统治权，都是掠夺性的，因而都不是正义的——只有非掠夺性的谋解放的战争才是正义的战争。日本受协定打击、前途更困难，但灭亡中国的根本目的决不会变更，不因内阁更换而改变，只是手段将从正面大规模进攻转向"以华制华"的政治进攻、"以战养战"的经济侵略和占领区的军事"扫荡"，并想经英国压迫中国投降，在适合的时机发起东方慕尼黑，以较大让步为钓饵诱胁中国订立城下之盟。中国的前途只有两个：坚持抗战、团结、进步的复兴前途，或实行妥协、分裂、倒退的亡国前途。我国战略退却阶段已完结，战略相持阶段已到来，相持阶段即准备反攻的阶段；故全国应以"准备反攻"为抗战的总任务，一面支持正面防御、援助敌后战争，一面实行各项改革、聚积力量，等时机一到就大举反攻、收复失地。

### 全文怎么推进
第一问评定苏德协定的意义：先指其来源，再逐层列出它对欧洲格局、对东方、对中国内部两派的实际改变，归结为为世界人民争取解放安置了基础 → 第二问纠正被倒置的因果：把破裂放回英法一贯的"不干涉"政策中，列出这一政策已造成的牺牲清单，摆出谈判的时间跨度与双方各自坚持和拒绝的条款，指明破裂原因，并给出该政策"始于损人、终于害己"的走向 → 第三问估计时局：判定帝国主义战争由片面性转入全面性的新阶段，按目的而非宣称判定欧洲大战为非正义，再依次估计英法德意集团、美国集团、日本、苏联四方 → 第四问回答中国前途：先给出互斥的两个前途，再判定我国已由退却阶段进入相持阶段并把相持定义为准备反攻，指出正面相持与敌后相持成反比例、敌后扫荡将加紧，对比国力相差很远 → 由此提出三项坚定的政治立场，每项写成"坚持—反对"的成对形式并附来源或范围清单 → 收束为总任务"准备反攻"，并拆为支持正面防御与援助敌后、实行改革与聚积力量两面。

##### 18、和中央社、扫荡报、新民报⑴三记者的谈话
### 为什么写
一九三九年九月十六日答中央社、《扫荡报》、《新民报》三记者问。据注释，中央社是国民党的中央通讯社，《扫荡报》是国民党政府军事系统的报纸，《新民报》是代表民族资产阶级的一种报纸——提问方来自对方阵营与中间方面，而非本党报刊。记者开场即说明，已看过九月一日刊于《新中华报》的谈话，此次是就写在纸上的问题表分三部分逐一请教，请作补充。此时相持阶段是否到来尚有争议；国民党秘密颁行的《限制异党活动办法》成为各地磨擦的根源，七月周恩来已写信给蒋委员长、八月一日延安各界又致电要求取消而未获答复；华北、华中相继发生磨擦与平江惨案；同时出现取消陕甘宁边区的主张。谈话即在这一场合就上述问题逐条作答。

### 主要在解决什么问题
要解决的是几类容易被推向极端或被偷换的判断：相持阶段到来是不是意味着敌人不会再进攻、我们可以立刻反攻；实行民主政治是不是要等训政期满、是不是要等老百姓有了知识；共同抗日的党派算不算"异党"、该不该被"限制"；面对内部磨擦，共产党到底是忍让还是还击，还击有没有界限；边区该不该按"统一"的要求取消；国共有没有分裂的可能，光靠两党的意愿够不够。这些问题都由对方阵营的记者提出，回答须在承认对方所据名义的前提下逐条给出可检验的界限。

### 作者最后给出的答案
相持阶段是"有条件地"到来的——在国际新形势、日本更加困难、中国绝不妥协的条件之下；这并不否认敌人还可能有较大的战役进攻，"基本上已经停止"不等于一切可能都没有了。新阶段的具体内容一概可用"准备反攻"统摄，但准备不是立即，讲的是战略反攻而非战役反攻，战役反攻不但会有而且必不可少。任务按区域分派：敌后坚持游击战争、粉碎"扫荡"、破坏经济侵略，正面巩固防御、打退可能的战役进攻，大后方主要是积极改革政治。因为敌人目前主要是政治进攻，就要特别加强政治抵抗，民主政治的问题应当快点解决；抗战主要依靠自力更生，而自力更生的主要内容就是民主政治。军政、训政、宪政的分期虽出于孙中山，但他在《北上宣言》里已不讲三个时期而主张立即召开国民会议，可见其主张"早就依据情势，有了变动"；"老百姓没有知识"之说不对，华北的区长、乡长、保甲长多是民选的，有些县长也已民选。共同抗日的军队叫友军不叫"异军"，共同抗日的党派就是友党不是"异党"；划界的标准是政治上有无丝毫共同之点——汪精卫的汉奸党才是异党，才应该限制，国共既同在抗日就应互相团结、互相协助。故当前是集中全力反日防日、反汪防汪的问题，不是反共防共的问题。汪精卫的口号是反蒋、反共、亲日，我们的口号必须与之逐条对立：他要反蒋我们就要拥蒋，他要反共我们就要联共，他要亲日我们就要抗日；凡是敌人反对的我们就要拥护，凡是敌人拥护的我们就要反对。对磨擦，根本反对抗日党派之间互相对消力量，但横逆一定要来时，态度是"人不犯我，我不犯人；人若犯我，我必犯人"，且须站在严格的自卫立场上，任何共产党员不许超过自卫原则。边区是全国政治上最进步的区域，且蒋委员长早已承认、行政院也已正式通过，取消无理由；中国确实需要统一，但应统一于抗战、团结、进步，向相反方向统一就会亡国。团结与分裂两种可能性都有，取决于两党尤其全国人民的态度；要彻底避免分裂，必须为长期合作找到政治保证，这就是坚持抗战到底和实行民主政治。

### 全文怎么推进
先答阶段问题：以条件限定宣布相持阶段到来，再用一串否定式圈出这一判断的边界（不否认较大战役进攻、不是立即反攻、不是战役反攻），用"准备反攻"统摄新阶段内容，并把任务按敌后、正面、大后方三处分派 → 由敌人当前主要是政治进攻，推出己方应特别加强政治抵抗，落到民主政治，并把它确认为自力更生在新环境下的主要内容 → 答如何实现：举孙中山本人在《北上宣言》中的变动破除三时期分期的束缚，再用华北民选的既成事实驳倒"老百姓没有知识" → 转入"限制异党"与磨擦：先陈述已提出抗议的方式与未获答复的事实，再用友军／友党的平行用法和"有无政治共同点"的标准重派"异党"所指，改写问题提法，并按与汪精卫口号逐条对立的方式确定己方口号 → 给出对磨擦的态度与自卫界限，并举华北、新四军两处实例 → 答取消边区：陈述边区性质，援引对方自己的承认与行政院的正式通过，再接过"统一"重申其方向 → 答分裂可能：承认两种可能都在，指出决定于谁的态度，最后要求为长期合作找到政治保证，并落到三大政治口号。

##### 19、苏联利益和人类利益的一致
### 为什么写

一九三九年九月二十八日，为纪念十月社会主义革命二十二周年，中苏文化协会向作者约稿。此前一个多月里连续发生三件震动舆论的大事：八月二十三日苏德订立互不侵犯条约，九月一日德国出兵侵入波兰、第二次世界大战爆发，九月十七日苏联进兵波兰东部；同时诺蒙坎停战协定刚签订，英美通讯社又纷传日苏互不侵犯协定将要订立。这些问题"目前正在中国广大人民中间议论着，似乎还没有得到确定的结论"。作者说明自己是"根据我的观察"，就几个和苏联、中国都有关系的问题提出意见，贡献给关心欧洲大战和中苏关系的人们作参考。

### 主要在解决什么问题

作者要纠正的是四类流行的错误认识：（1）认为苏联利于爆发世界大战、不要求和平继续，大战由苏德互不侵犯条约所促成；（2）认为大战既已爆发，苏联红军将参加德国帝国主义战线，并把苏德通商当作参战的证据；（3）对苏联进兵波兰"糊涂起来"，不加分解地笼统评判；（4）因诺蒙坎停战协定与日苏条约传闻而忧虑苏联将不再援助中国。这些认识之所以重要，是因为英美法的阴谋家和中国的投降派正借此掀风鼓浪、挑拨中苏两大民族间的感情，直接关系到中国抗战派与投降派的力量对比和抗日外交方针的选择。

### 作者最后给出的答案

全文的核心判断是：苏联的利益和世界人类大多数的利益互相联系、互相一致，同中国民族解放的利益也永久一致；这一"基本原则"既解释苏联已有的行为，也可用来预判它尚未发生的行为。据此得出四个结论：苏联长期尽力维持和平到最后一刻，大战是英法拒绝同苏联订立平等互惠互助条约、纵容挑拨战争所促成；苏联对性质同为帝国主义的交战双方严守中立，只援助正义的、谋解放的战争，通商既不是援助更不是参战；进兵波兰是收复国土、解放弱小民族并击破张伯伦推动德国东进的阴谋，属正义行动；日苏条约即使订立，苏联也决不会在条约中限制自己援华。最后给出中国的外交政策：以自力更生为主，争取三方面可靠外援，对帝国主义交战各国严守中立。

### 全文怎么推进

针对国人议论纷纷而无定论的四个问题逐一作答 → 一、逐项列举苏联多年来的实际行为（加入国联、订苏法苏捷互助协定、援助西班牙政府军、同中国订约并援助抗日、揭穿慕尼黑黑幕、同英法谈判四个多月），证明其对外政策一贯是和平政策，进而把大战爆发的责任落到拒绝同苏联妥协的英美法身上，"拒绝了苏联，就是拒绝了和平" → 二、判定现爆发的战争双方同属非正义的、掠夺的、帝国主义性质，故苏联必然对双方严守中立、只援助谋解放的战争，并用西班牙、中日两个反例区分通商、援助与参战三种不同性质的关系 → 三、把波兰问题拆成德国、英法、波兰政府、波兰人民、苏联五个方面分别判定，再还原摆在苏联面前的两条现实道路和张伯伦引诱德国东进的阴谋，得出苏联行动完全正义 → 四、说明苏德条约后的形势打击日本、加强抗战派，诺蒙坎协定与日苏条约传闻都不会改变苏联援华，进而给出中国外交政策的主次结构与中立边界 → 五、结语点明讨论国际问题的目的是为了中国抗日的胜利。

##### 20、《共产党人》发刊词
### 为什么写

一九三九年十月四日，中共中央创办党内刊物《共产党人》，作者为它写发刊词。中央很早就计划出版这样一个党内刊物，此时"算是实现了"。当前时机有两个特点：一方面抗日民族统一战线中的投降危险、分裂危险和倒退危险日益发展，大资产阶级投降派和顽固派在思想上企图"溶解"共产主义，在政治上、组织上企图取消共产党、取消边区、取消党的武装力量；另一方面党已经走出狭隘的圈子、变成了全国性的大党，大批新党员形成了很多新组织。刊物的任务是帮助建设"一个全国范围的、广大群众性的、思想上政治上组织上完全巩固的布尔什维克化的中国共产党"，作者认为这件伟大工程"不是一般党报所能胜任的，必须有专门的党报"。

### 主要在解决什么问题

作者要回答的问题层层递进：（1）党在某种程度上已经是全国性的、群众性的、思想政治组织上巩固的党，为什么还要提出新的建设任务；（2）建设这样一个党"究竟应该怎样进行"，能不能就党建谈党建；（3）中国革命有哪些不同于资本主义国家的规定性，这些规定性由什么产生；（4）在同资产阶级的关系上，"左"倾关门主义与右倾机会主义两种方向相反的错误怎样同时防止；（5）统一战线、武装斗争、党的建设三者是并列的三项工作还是有确定的相互关系；（6）党在不同阶段犯过方向相反的错误，它们是各自孤立的还是有共同根源。这些问题直接关系到党能否克服当前的投降、分裂、倒退危险并准备对付可能的突然事变。

### 作者最后给出的答案

由半殖民地半封建、发展不平衡、半封建经济占优势而土地广大的社会状况，规定了革命的性质、对象、动力和主要斗争形式；由此归结出中国资产阶级民主革命的两个基本特点：无产阶级同资产阶级建立或被迫分裂革命的民族统一战线，主要革命形式是武装斗争。两个基本特点又规定了统一战线、武装斗争、党的建设这三个基本问题，"正确地理解了这三个问题及其相互关系，就等于正确地领导了全部中国革命"；十八年经验使党已能对三者作出正确结论，它们是战胜敌人的三个主要法宝。三者的相互关系是：统一战线和武装斗争是两个基本武器，统一战线是实行武装斗争的统一战线，党的组织则是掌握这两个武器实行对敌冲锋陷阵的英勇战士。党的建设过程始终联系于对这两个问题处理得正确与否，反过来党更加布尔什维克化才能更正确地处理它们。最终任务是：根据马克思列宁主义的理论和中国革命的实践之统一的理解，集中十八年的经验和当前的新鲜经验传达到全党，使党铁一样地巩固起来，而避免历史上曾经犯过的错误。

### 全文怎么推进

从刊物出版的必要性和当前时机的两个特点出发 → 提出刊物任务即帮助建设全国范围的、广大群众性的、思想上政治上组织上完全巩固的布尔什维克化的党 → 自问既已在某种程度上达到，为何还提出新任务，答以新党员所成的新组织尚未巩固、老党员老组织需要提高，且环境比国内革命战争时期复杂得多、任务艰巨得多 → 再问"究竟应该怎样进行"，指出这个问题同十八年斗争史不能分离 → 由中国的社会状况推出革命的性质、对象、动力与主要形式，归纳出统一战线与武装斗争两个基本特点，并说明为何不把党同农民、党同城市小资产阶级的关系列为特点 → 由两个基本特点推出党的建设过程始终受制于对这两个问题的处理，并给出反向论断 → 确立统一战线、武装斗争、党的建设为三个基本问题即三大法宝 → 依次按三个历史阶段考察统一战线（六条规律与两条战线斗争）、武装斗争（三阶段与游击战争）、党的建设（三阶段的成绩与错误） → 归结三者关系为两个武器加掌握武器的战士 → 落到"今天要怎样建设我们的党"，答案是把党建同统一战线、武装斗争联系起来看 → 末句给出总任务。

##### 21、目前形势和党的任务
### 为什么写

据编者说明，这是一九三九年十月十日毛泽东为中共中央起草的决定。此前一个多月国际国内形势连续剧变：第二次世界大战爆发，苏德订立互不侵犯条约，苏联出兵波兰东部；国内武汉失守已近一年，日本对华方针发生转变，由大规模战略进攻转为专力"解决中国问题"，对国民党后方以政治进攻为主，着重分化抗日统一战线、引诱投降；同时大地主大资产阶级的反共磨擦与倒退现象不断发展。中央需要对变化了的国际国内形势作出统一判断，并据以规定全党在敌后、正面和后方三个方面的任务，故起草这一决定。

### 主要在解决什么问题

决定要解决的判断与部署问题包括：（1）新爆发的世界大战应如何定性，苏联的一系列行动应如何看待；（2）日本在国际新形势下的方针究竟是什么，它对占领区和对我后方分别用什么手段，主要手段是不是军事手段；（3）抗战是否已经进入新的阶段，这一判断的根据是什么，又该加上哪些限制才不致引起松懈；（4）当前时局中的最大危险是什么，正在发生的反共现象和倒退现象究竟只是磨擦还是别有指向；（5）在敌后方、正面和我后方三个不同方向上分别应当做什么，党自身又该如何准备可能发生的突然事变。

### 作者最后给出的答案

世界大战无论德国方面或英法方面都是非正义的掠夺的帝国主义战争，全世界共产党都应坚决反对；苏联依然坚持和平政策、对战争双方严守中立，出兵波兰是制止德国侵略势力东扩、巩固东欧和平、解放被压迫民族。日本的方针是专力进攻中国：对占领区域加以确保，为此"扫荡"游击根据地、进行经济开发、建立伪政权、消灭中国人的民族精神；对我后方以政治进攻为主、军事进攻为辅，着重分化统一战线、分裂国共合作、引诱国民党政府投降。由于敌人受二年余抗战打击、兵力财力不足，大规模战略进攻的可能性已经不大，"抗战的战略相持阶段基本上已经到来"，而相持阶段即是准备反攻阶段；但同时立三条限制：不否认仍有战役进攻，"扫荡"将加重，若不能破坏占领地、不能打退政治进攻或政府自动投降，相持局面仍会被破坏。当前最大危险仍是投降、分裂、倒退，反共和倒退现象是大地主大资产阶级准备投降的步骤。任务是切实执行"坚持抗战反对投降、坚持团结反对分裂、坚持进步反对倒退"三大政治口号以准备反攻力量，并按敌后方、正面、我后方分置具体方针，同时从思想上政治上组织上巩固党及其领导的军队和政权，准备对付可能的突然事变。

### 全文怎么推进

先判定国际战争的性质和苏联行动的性质，为全局定下基调 → 再判定敌人在国际新形势下的总方针是专力解决中国问题，并按"占领区域"与"我后方"两个方向分列其目的与手段，指出在我后方它以政治进攻为主而非军事进攻为主 → 由敌人所受打击和兵力财力不足推出大规模战略进攻可能性已不大，据此作出"战略相持阶段基本上已经到来"的阶段判断，并说明这一阶段的实际内容是准备反攻 → 判断作出后立即用三条限制加以约束：仍有战役进攻、"扫荡"将加重、若干条件不具备则相持局面仍会被破坏 → 由此确认投降、分裂、倒退仍是最大危险，并把反共倒退现象判定为准备投降的步骤 → 落到党的任务，先给三大政治口号，再按敌后方、正面、我后方三个方向分列性质不同的方针 → 最后要求提高警觉性、巩固党与军队政权，准备对付可能的突然事变。

##### 22、大量吸收知识分子
### 为什么写

据编者说明，这是一九三九年十二月一日毛泽东为中共中央起草的决定。抗战进入战略相持阶段，党已从狭小圈子变成全国性大党，要在长期的和残酷的民族解放战争中组织伟大的抗战力量、组织千百万农民群众、发展革命的文化运动和革命的统一战线，都需要大批知识分子。三年以来党和军队在这方面已经尽了相当努力、吸收了大批革命知识分子，是一个大的成绩；但许多军队中的干部还存着恐惧知识分子甚至排斥知识分子的心理，许多学校不敢放手地大量地招收青年学生，许多地方党部不愿意吸收知识分子入党。同时资产阶级政党正在拚命地同我们争夺知识分子，日本帝国主义也在利用各种方法收买和麻醉中国知识分子。中央为纠正这些偏向、统一全党政策而作出此决定。

### 主要在解决什么问题

要解决的是党内对待知识分子的错误态度及其认识根源：不懂得知识分子对于革命事业的重要性；不懂得殖民地半殖民地国家的知识分子和资本主义国家的知识分子的区别；不懂得为地主资产阶级服务的知识分子和为工农阶级服务的知识分子的区别；不懂得对方正在争夺知识分子的严重性；尤其不懂得党和军队已经造成中坚骨干、已有掌握知识分子的能力这一有利条件。由此还派生两个操作难题：一是大量吸收与保证组织纯洁如何并行——既不放松对派遣分子和不忠实分子的拒绝，又不因此怀疑忠实的知识分子、不让反革命分子借机陷害好人；二是知识分子干部与工农干部之间的隔阂如何消除，避免一方排斥另一方。

### 作者最后给出的答案

共产党必须善于吸收知识分子，"没有知识分子的参加，革命的胜利是不可能的"；对于知识分子的正确的政策，是革命胜利的重要条件之一。方针是大量吸收：凡愿意抗日的、比较忠实的、比较能吃苦耐劳的知识分子都应多方吸收，加以教育，使他们在战争中在工作中磨练，为军队、为政府、为群众服务；具备入党条件者按具体情况吸收入党，不能或不愿入党者也建立良好的共同工作关系、带领一道工作。同时在大量吸收政策之下充分注意拒绝对方派遣进来的分子和不忠实分子，已混进者依靠真凭实据坚决地有分别地洗刷出去，但不因此怀疑比较忠实的知识分子，严防反革命分子陷害好人。对已吸收者分配适当工作、教育带领，使其革命化和群众化，同老党员老干部和工农党员融洽起来。对反对吸收的干部切实说服，同时鼓励工农干部加紧学习，使"工农干部的知识分子化和知识分子的工农群众化，同时实现起来"。在国民党统治区和日寇占领区基本适用上述原则，但入党时更多注意忠实程度；对党外同情者建立适当联系并组织到抗日、民主、文化和统一战线工作中去。土地革命时期的不正确态度决不应重复；无产阶级自己的知识分子的造成，也决不能离开利用社会原有知识分子的帮助。

### 全文怎么推进

先从任务规模确立必要性：长期残酷的民族解放战争和建立新中国的斗争都要求善于吸收知识分子，没有他们革命胜利不可能 → 再把现状分成成绩与偏向两面，列出偏向的三种具体表现（军队干部恐惧排斥、学校不敢招收、地方党部不愿吸收入党），并把原因归结为五个"不懂得"，其中包含两组关键区别和一项己方已具备的有利条件 → 由此提出五项办法：大量吸收并按合乎程度分层安置；在大量吸收之下严格拒绝与洗刷，同时立下不得怀疑一般忠实者、严防陷害好人的反向限制；对已吸收者教育带领使其革命化群众化并同老干部工农党员融洽；对反对吸收的干部说服，同时提高工农干部文化水平，使两个方向的转化同时实现；在国统区和敌占区保持原则适用而提高入党的忠实程度要求，并把党外同情者组织到各条工作战线 → 最后上升为认识：正确政策是革命胜利的重要条件之一，历史上的不正确态度决不应重复，自己的知识分子的造成也离不开原有知识分子的帮助。

##### 23、中国革命和中国共产党
### 为什么写

据编者说明，这是一九三九年十二月毛泽东与他人合作写作的课本（第一章由其他同志起草、经毛修改，第二章毛自写；原拟第三章《党的建设》未完稿）。文章的任务是向党内和全国人民系统说明"中国社会"与"中国革命"的一系列基本问题。第二章关于新民主主义的观点后来在一九四○年一月的《新民主主义论》中大为发展。当时抗战进入相持阶段，需要在理论上回答中国革命"是什么、为什么、怎么办"，以统一全党对中国革命各项基本问题的认识。

### 主要在解决什么问题

文章要澄清的是一组根本问题的认识顺序与根据：革命的对象、任务、动力、性质、前途各是什么，以及它们之间如何推导。它针对的混乱在于——不能从国情（社会性质）出发系统地推演这些派生问题，而在阶级态度、革命对象与动力、革命性质与前途等问题上容易孤立地、表面地作答；也容易对某一大类（如"农民""资产阶级"）作整体定性，或把两个性质不同的革命过程混为一谈或割裂开来。

### 作者最后给出的答案

认清中国社会的性质（国情）是认清一切革命问题的基本根据。由此推演：革命对象是帝国主义和封建主义，最主要反对帝国主义；任务是对外推翻帝国主义的民族革命与对内推翻封建地主的民主革命，二者互相关联、民族革命是主要任务；动力是工人、农民、小资产阶级和民族资产阶级（在一定时期一定程度上），农民是主力军、无产阶级是领导；性质是新民主主义（特殊的新式资产阶级民主主义）革命；前途是社会主义。对兼具两重性的阶级（民族资产阶级、大资产阶级顽固派）实行联合又斗争；对大类内部再分级（农民分富农、中农、贫农；资产阶级分带买办性的大资产阶级与民族资产阶级）。民主主义革命与社会主义革命是性质不同的两个过程，前者是后者的必要准备、后者是前者的必然趋势，领导责任都在共产党。

### 全文怎么推进

从中华民族与古代封建社会的历史定位出发（说明中国长期停滞的封建经济政治与农民革命传统） → 分析近代社会如何从封建变为半殖民地半封建（帝国主义的双重作用、六大特点、两大主要矛盾） → 由社会性质推出革命对象，进而推出革命任务并说明二者互相关联 → 按各阶级经济地位系统分析革命动力（地主、资产阶级、小资产阶级、农民、无产阶级、游民） → 再由社会性质推革命性质（新民主主义），并由已存在的社会主义因素推前途（社会主义） → 最后总结革命的两重任务与共产党不可代替的领导责任。

##### 24、斯大林是中国人民的朋友
### 为什么写

一九三九年十二月二十日是斯大林六十岁生日。文章借庆祝之机，针对当时国内存在的对"谁是朋友"的糊涂认识——有人不加思索地把口称同情中国的帝国主义者也称做朋友——明确回答"谁是我们的朋友"这一事关抗战前途的根本问题。

### 主要在解决什么问题

要澄清的是判断朋友的标准：不能看对方是否自称朋友或口头同情，而要看其实际行为。文章要揭露"口蜜腹剑"的帝国主义者假朋友本质，同时确立苏联和斯大林作为真正朋友的地位，以巩固对社会主义国家援助的信赖，并驳斥各种挑拨离间。

### 作者最后给出的答案

朋友不靠自称，而靠实际行动判定。帝国主义者口称同情中国、自命朋友，却是"口蜜腹剑"的假朋友；苏联和斯大林拿真正同情给我们、把我们当弟兄，是真正的朋友。三条铁证：没有国家废除在华特权而只有苏联废除；大革命时期一切帝国主义反对中国而只有苏联援助；抗战以来没有帝国主义政府真正援助中国而只有苏联以空军和物资援助。结论：只有社会主义的国家、领袖、人民、思想家、劳动者才能真正援助中国解放事业，没有他们的援助不能取得最后胜利；斯大林是忠实朋友，中国人民的敬爱完全出于诚意，任何挑拨离间终归无用。

### 全文怎么推进

由庆祝斯大林生日引出拥护社会主义方向 → 指出中国正处在最需要援助的灾难时刻、亟需辨明朋友 → 设问"谁是我们的朋友" → 把朋友分为自称的假朋友（口蜜腹剑的帝国主义者）与真正同情我们的真朋友（苏联/斯大林）两类 → 用三条事实（废除特权、大革命援助、抗战援助）证明只有苏联是真正朋友 → 归纳：只有社会主义力量才能真正援助 → 强调敬爱出于诚意、挑拨离间无用。

##### 25、纪念白求恩
### 为什么写
1939 年 12 月 21 日作。据注释，白求恩是加拿大共产党员、著名医生，一九三六年曾赴西班牙前线为反法西斯人民服务；中国抗战爆发后，他受加拿大共产党和美国共产党派遣，率加美医疗队于一九三八年三月底到延安，不久赴晋察冀边区工作一年多，一九三九年十一月十二日因施行急救手术受感染在河北唐县逝世。作者与他仅见过一面，因忙只回过一封信，对其死"很悲痛"。文章借纪念这位外国医生，向全党提出应当学习什么精神的问题。

### 主要在解决什么问题
文章针对的不只是哀悼，而是党内存在的两类实际问题。一是工作态度问题：不少人对工作不负责任，拈轻怕重、把重担子推给人家，一事当前先替自己打算，出了一点力就自吹，对同志对人民不是满腔热忱而是冷冷清清、漠不关心、麻木不仁。二是对本职技术的轻视：一班人见异思迁，鄙薄技术工作，以为不足道、以为无出路。此外还要解决立场认识问题——如何看待一个外国人为中国事业工作，以及如何反对狭隘民族主义和狭隘爱国主义。

### 作者最后给出的答案
一个外国人毫无利己的动机，把中国人民的解放事业当作他自己的事业，这是国际主义的精神、共产主义的精神，每个中国共产党员都要学习。列宁主义认为资本主义国家无产阶级与殖民地半殖民地人民须互相拥护对方的解放斗争，世界革命才能胜利；白求恩实践了这条路线，中国共产党员也要实践，同一切资本主义国家的无产阶级联合起来。毫不利己专门利人具体表现为对工作极端负责任、对同志对人民极端热忱；对技术则精益求精。最后给出普遍标准：从毫无自私自利之心这一点出发就可以变为大有利于人民的人；能力有大小，但只要有这点精神，就是一个高尚的人、纯粹的人、有道德的人、脱离了低级趣味的人、有益于人民的人。

### 全文怎么推进
叙述白求恩身份、来华与殉职 → 追问"一个外国人，毫无利己的动机……这是什么精神" → 判定为国际主义、共产主义精神，并接上列宁主义的相互拥护路线，推出中国共产党员也要联合一切资本主义国家无产阶级、以此反对狭隘民族主义和狭隘爱国主义 → 转入"毫不利己专门利人"的两项可观察表现（对工作极端负责、对同志对人民极端热忱），并与党内不负责任、自私自利者对照，指出后者"不能算一个纯粹的共产党员" → 以前线归来者与边区军民的普遍感动作旁证 → 举其医术高明，教训见异思迁与鄙薄技术工作的人 → 以个人交往与悲痛收束，落到"学习他毫无自私自利之心的精神"和五项做人标准。

##### 26、新民主主义论
### 为什么写
据编者说明，这是一九四〇年一月九日在陕甘宁边区文化协会第一次代表大会上的讲演，原题《新民主主义的政治与新民主主义的文化》，载于同年二月十五日延安出版的《中国文化》创刊号，二月二十日《解放》第九十八、九十九期合刊登载时改题为《新民主主义论》。作者在开篇说明直接起因：抗战以来全国人民本有一种欣欣向荣的气象，但近来妥协空气、反共声浪又甚嚣尘上，把全国人民打入闷葫芦里，文化人和青年学生感觉锐敏、首当其冲，"中国向何处去"重新成为问题。因此趁《中国文化》出版，说明中国政治和中国文化的动向。

### 主要在解决什么问题
要解决的不是一个文化学术问题，而是一串互相纠缠的现实认识问题：中国究竟要建立什么样的新社会新国家，新文化到底是什么样子；国内能不能走资产阶级专政的资本主义道路；能不能现在就实行社会主义，"毕其功于一役"；恶意宣传家提倡的"一次革命论"、"共产主义不适合中国国情"、要共产党把共产主义"收起"、"一个主义"等说法如何驳倒；顽固派不知新旧三民主义之别、以反俄反共反农工冒充三民主义；文化上则有资产阶级的文化专制主义，以及把整个国民文化径直当作社会主义文化的偏向，还有"全盘西化"和对古代文化无批判地兼收并蓄。

### 作者最后给出的答案
现时中国是殖民地、半殖民地、半封建社会，这一性质决定革命必须分两步：第一步是民主主义革命，第二步是社会主义革命；而第一步已不是旧民主主义，而是新民主主义，并且自一战和十月革命之后已成为无产阶级社会主义世界革命的一部分。据此：新政治的国体是各革命阶级联合专政，政体是民主集中制；新经济是大银行大工业大商业归国家所有、节制资本、平均地权、耕者有其田，同时不没收其他资本主义私有财产；新文化是无产阶级领导的人民大众反帝反封建的文化，即民族的、科学的、大众的文化。三者结合就是新民主主义共和国。同时划清两条界限：不走资产阶级专政的资本主义道路，也不在现阶段实行社会主义；共产党有最低纲领与最高纲领两部分；新三民主义以联俄、联共、扶助农工三大政策为判据，缺一即为伪。

### 全文怎么推进
由"中国向何处去"提出问题 → 提出要建立包含新政治、新经济、新文化的新中国 → 以"一定的文化是一定社会的政治和经济的反映，又给予伟大影响和作用于政治经济"为基本观点，判定现时社会性质，从而定出革命两步走与新民主主义 → 说明这个历史特点不是鸦片战争以来就有，而是在一战和十月革命之后形成，中国革命由旧范畴转入新范畴、成为世界社会主义革命的一部分 → 展开新民主主义的政治（国体与政体）与经济（节制资本、平均地权）→ 从国际环境与国内环境两面驳资产阶级专政，再驳"左"倾空谈主义的"一次革命论"与"毕其功于一役" → 驳顽固派"收起共产主义"，分列三民主义与共产主义的相同与不同 → 区分新旧三民主义，以三大政策为可检验判据 → 转入文化，说明新民主主义文化的性质、五四前后两个时期与文化战线的四个时期 → 纠正文化性质上的偏向 → 落到民族的、科学的、大众的文化，与新政治新经济结合成新民主主义共和国。

##### 27、克服投降危险，力争时局好转
### 为什么写
据编者说明，这是一九四〇年一月二十八日毛泽东为中共中央起草的对党内的指示。直接背景见注释：一九三九年十一月日本帝国主义把《日支新关系调整要纲》交付汪精卫集团，汪集团于同年十二月三十日与日方秘密签订，一九四〇年一月由脱离该集团的高宗武、陶希圣在香港公布；一九四〇年一月二十四日国民党中央社发表蒋介石《为〈日汪密约〉告全国军民书》。此时各地投降、反共、倒退现象接连发生，国民党顽固派推行"军事限共"和"政治限共"。指示要向全党说明对时局的估计、当前总方针和随后的具体行动。

### 主要在解决什么问题
要纠正党内在严重现象面前可能出现的两种偏差：一是把各地发生的投降、反共、倒退现象孤立起来看，认识不到其严重性；二是被这些现象的威力所压倒，或者只从惧怕破裂统一战线一点设想，因而不敢坚决反抗。作者指出，如果听任"军事限共""政治限共"发展下去，抗战前途就是危险的，投降和反共将全国化，统一战线有破裂的危险。此外还要解决在汪精卫卖国协定公布、蒋介石发表告国人书之后，如何判断形势的两面走向、如何把方针转成各地可执行的宣传与行动。

### 作者最后给出的答案
大地主大资产阶级的投降方向与无产阶级、农民、城市小资产阶级、中等资产阶级的抗战方向是对立的，目前两种方向同时存在，两种前途都有可能。必须认清尚存在许多有利于争取继续抗战、继续团结、继续进步的客观条件：国际上日本对华方针依然强硬，英美法同日本的矛盾并未真正协调，英法在东方的地位又被欧战削弱，所谓远东慕尼黑会议很难召集，苏联积极援助中国；国内共产党和八路军新四军坚决反对投降，中间阶级也反对投降，投降派顽固派虽握有权力但数量上只占少数。据此，党的任务是双管齐下：一面坚决反抗军事进攻和政治进攻，一面积极发展各方面的统一战线并逐项力争。总方针是"力争时局好转，同时提起可能发生突然事变（在目前是局部的、地方性的突然事变）的警觉性"。具体做法是极力扩大反对汪精卫卖国协定的宣传，提出十一项公开口号，各地在二月上中旬普遍举行民众大会。

### 全文怎么推进
以时局发展证明中央历次估计正确开篇 → 指出两种方向对立、两种前途都有可能 → 纠正孤立看待与被威力压倒两种偏差，指明听任其发展的后果 → 逐条列举国际与国内的有利客观条件 → 由这些条件定出双管齐下的党的任务 → 归结为"力争好转 + 提起对突然事变的警觉"的总方针 → 分析汪蒋两事之后形势的两面（和平空气受打击、抗战势力发展；"限共"仍会继续、地方事变还会发生）→ 指出蒋介石宣言的缺口：表示继续抗战，但没有强调加强团结、没有提坚持抗战和进步的方针 → 就此提出反汪运动中应强调的十一项口号并要求公开发布、各地增补 → 落到统一日程：延安二月一日、各地二月上中旬普遍举行民众大会。

##### 28、团结一切抗日力量，反对反共顽固派
### 为什么写
据编者说明，这是一九四〇年二月一日毛泽东在延安民众讨汪大会上所作的讲演。会议的直接由头是声讨卖国贼汪精卫：汪订立了日汪卖国条约，还要成立傀儡政府和傀儡军队，与抗日政府、抗日军队相对立。与此同时，国民党内的反共顽固派在各地制造事端——据注释，一九三九年六月张荫梧部袭击河北深县八路军后方机关杀害四百余人，同年三月秦启荣部在山东博山伏击八路军受训干部、到一九四〇年春已残杀七百余人，六至九月程汝怀在鄂东惨杀共产党员五六百人，十一月河南确山（竹沟）惨案杀害二百余人，十二月阎锡山调六个军进攻新军；对陕甘宁边区则有"点线工作"、封锁并准备军事进攻，还设集中营囚禁进步青年，雇张君劢提出取消共产党、边区和八路军新四军的主张。讲演要在声讨汪精卫的同时，说清楚对国民党各部分人的政策。

### 主要在解决什么问题
要纠正群众看到这种局面后的一种反应："许多人看了这种情形，非常气愤，就以为抗日没有希望了，国民党都是坏人，都应当反对。"这既包含悲观，也包含按所属身份作无差别打击。同时要回答两个被对方抢占的问题：一是有些人单单强调抗日，不愿意强调甚至完全不提团结和进步；二是反共顽固派高唤"统一"，实则要取消共产党、八路军、新四军和陕甘宁边区，把全国一切都化为国民党，借统一之名行专制之实。

### 作者最后给出的答案
气愤是完全正当的，但抗日仍然是有希望的，国民党里面也不都是坏人，对各部分的国民党人应当采取不同的政策：对制造惨案磨擦、向进步力量下手的丧尽天良的坏蛋决不容忍、必定还击、决不让步，不加惩罚就是纵容汉奸国贼、就是违背党的政策；对忠心抗日的、一切非投降派非反共顽固派的人们表示好意、团结、尊重，愿意长期合作，不这样做同样是违背党的政策。这就是两条政策，服务于一个目的：力争时局好转、战胜日本。关于"统一"，提出自己的统一论：以抗战、团结、进步三件事做基础——只有进步才能团结，只有团结才能抗日，只有进步、团结、抗日才能统一；不以这三件事为基础的统一是假统一、不合理的统一、形式主义的统一。结论是不取消边区、八路军新四军和共产党，而是全国要学习它们，落后的人们向进步的人们看齐。

### 全文怎么推进

##### 30、《中国工人》发刊词
### 为什么写

### 主要在解决什么问题

要解决的是：怎样让一份工人刊物真正服务于工人阶级的当前任务，而不是空有其名。包括：工人运动当前该围绕什么目标展开（如何区分最终解放与当前民主革命阶段）；刊物应当讲什么、怎么讲（通俗解释道理、报道斗争实际、总结斗争经验，并教育培养干部）；工人队伍自身力量不足时怎么办（欢迎革命知识分子的帮助）；以及怎样避免刊物办得死板老套、无人爱看、无人参与。

### 作者最后给出的答案

工人阶级和全体人民的最后解放只能在社会主义实现的时代，但必须经过反帝反封建的民主革命阶段才能进到社会主义。所以当前任务是：团结自己和团结人民，反对帝国主义和封建主义，为建立新民主主义的中国而奋斗；《中国工人》的出版就是为了这一任务。刊物应以通俗的言语解释道理、报道工人阶级抗日斗争的实际、总结其经验，办成教育工人、训练工人干部的学校，培养出"有知识，有能力，不务空名，会干实事"的大批干部；工人应欢迎革命知识分子的帮助而不可拒绝，否则自己不能进步、革命不能成功。办刊要求多载生动的文字、切忌死板老套，并把办好看作办的人与看的人共同的责任，看的人提出意见、写短信短文寄去、表示欢喜什么不欢喜什么，报才能办得好。

### 全文怎么推进

##### 31、必须强调团结和进步
### 为什么写
一九四○年二月七日作。据编者说明，这是为延安《新中华报》改版一周年纪念写的文章。此前一年国内政治形势明显逆转：汪精卫公开叛国，订立卖国协定并筹组伪政府；国民党方面不承认共产党的合法地位，雪片一样下发"限制异党活动"的文件。据注释，一九三九年十二月阎锡山发动"晋西事变"，进攻新军并公开摧残牺盟会，许多共产党员、牺盟会干部和进步分子遭残杀；自一九三九年起，国民党又借三民主义青年团"招待所"的名义，在咸阳榆林公路和陇海铁路一带设立封锁站口，截留出入陕甘宁边区的进步青年和知识分子，送往集中营监禁残杀。作者借报纸纪念之机重申共产党在上年"七七"纪念时提出的三大方针，并为报纸第二年确定政治方向。

### 主要在解决什么问题
要解决的是把"抗战"同"团结""进步"割裂开来的认识和做法。当时存在一种只讲抗战、不讲团结和进步的态度：口头上拥护抗战，实际上搞分裂运动、制造内部磨擦、从抗日阵线后面进攻八路军新四军和一切进步势力、破坏敌后抗日根据地和陕甘宁边区；或者在政治上倒退——把三民主义和《抗战建国纲领》束之高阁，不实行《总理遗嘱》"唤起民众"的指示，取消抗战初期仅有的一点言论出版自由，把宪政运动变为少数人包办的官僚事业，同时贪官污吏横行、土豪劣绅猖獗、发国难财。作者要回答的是：只剩下"抗战"两个字的方针能不能维持抗战本身。

### 作者最后给出的答案
抗战、团结、进步是三位一体的方针，三者不可缺一，一定要三者合一。如果单单强调抗战而不强调团结和进步，所谓"抗战"是靠不住的、不能持久的；缺乏团结和进步纲领的抗战，终久会有一天要改为投降，或者归于失败。三项方针的实际内容由各自明确的反对对象界定：为了抗战就要反对投降，反对汪精卫的卖国协定和伪政府，反对暗藏在抗日阵线中的汉奸和投降派；为了团结就要反对分裂运动和内部磨擦，反对从背后进攻八路军、新四军和进步势力，反对破坏抗日根据地和陕甘宁边区，反对不承认共产党的合法地位，反对"限制异党活动"的文件；为了进步就要反对倒退，从束之高阁的纲领、被取消的言论出版自由、被包办的宪政运动，一直反对到拦路劫人、发国难财和贪官污吏土豪劣绅。据此，《新中华报》第二年的政治方向就是强调团结和进步，以反对一切危害抗战的乌烟瘴气。

### 全文怎么推进
提出抗战、团结、进步三大方针并断定其为三位一体、缺一不可 → 反证：单单强调抗战而缺团结和进步纲领，抗战靠不住、不能持久，终久会改为投降或归于失败 → 由"为了抗战""为了团结""为了进步"三个方向分别展开具体的反对清单，把方针落到可指认的现实事项上 → 收束为反命题：不这样做，没有团结和进步，所谓抗战只是空唤，抗日胜利没有希望 → 落到报纸自身，宣布《新中华报》第二年的政治方向就是强调团结和进步。

##### 32、新民主主义的宪政
### 为什么写
一九四○年二月二十日在延安各界宪政促进会成立大会上的演说。据编者说明，这时中国共产党内有一些同志为蒋介石的所谓实行宪政的欺骗宣传所迷惑，以为国民党或者真会实行宪政；作者在演说中揭露这种欺骗，并把促进宪政变为启发人民觉悟、向蒋介石要求民主自由的一个武器。据注释，一九三九年九月国民参政会第一届第四次会议根据中国共产党和其他党派民主人士的提议，通过了要求国民党政府明令定期召集国民大会实行宪政的决议；同年十一月国民党五届六中全会宣布于一九四○年十一月十二日召集国民大会，并借此大作欺骗宣传，而这些决议后来都没有实行。会议由吴玉章任理事长，作者的演说紧接其发言而作。

### 主要在解决什么问题
要解决四个纠缠在一起的认识问题。第一，宪政要的究竟是哪一种民主政治：顽固派口称欧美旧式民主而实要法西斯主义的一党专政，民族资产阶级确实想要资产阶级专政却要不来，社会主义的民主虽好但在当时的中国还行不通。第二，中国的宪政运动与外国宪政在事实前提上有何根本区别——外国是革命成功、已有民主事实之后立法承认，中国则革命尚未成功、除边区等地外尚无民主政治的事实。第三，怎样识破"挂宪政的羊头，卖一党专政的狗肉"的两面派，避免把颁布宪法、选举总统当成宪政到手。第四，既然顽固分子今天顽固、明天顽固、后天还顽固，宪政到底还有没有希望。

### 作者最后给出的答案
中国主要少了独立和民主两件东西，同时多了帝国主义的压迫和封建主义的压迫两件东西，所以必须坚决地彻底地破坏这些坏东西，不破坏就休想建设；把独立和民主合起来，就是民主的抗日，没有民主抗日就抗不下去。宪政就是民主的政治，但当前要的既不是旧的、过了时的、欧美式的资产阶级专政的民主，也还不是苏联式的无产阶级专政的民主，而是新民主主义的宪政——几个革命阶级联合起来对于汉奸反动派的专政，即孙中山《中国国民党第一次全国代表大会宣言》所说的"为一般平民所共有，非少数人所得而私"，这样的宪政也就是抗日统一战线的宪政。中国的宪政运动是争取尚未取得的民主，不是承认已经民主化的事实，因而是一个大斗争，决不会因为开会、打电报、颁布宪法甚至选举大总统就实现。顽固分子虽然顽固，却是"顽而不固"，凡属倒退行为结果都和主持者原来的愿望相反，古今中外没有例外；宪政运动的方向由全国人民、中国的历史发展和整个世界的趋势规定，加上顽固派到底是少数，所以事情虽然困难，却大有希望，办法是研究和推动，到处开会、写文章、发通电，做他几年。

### 全文怎么推进
从会议宗旨"发扬民意，战胜日本，建立新中国"入手 → 指出中国少了独立与民主两件、多了帝国主义与封建主义两重压迫，故必须先破坏后建设，并把独立和民主合为"民主的抗日" → 定义宪政就是民主的政治，再逐一排除已经没落的欧美旧式民主与条件未到的社会主义民主，确定为新民主主义的宪政 → 给出正面定义：几个革命阶级联合起来对于汉奸反动派的专政，并引孙中山宣言"为一般平民所共有，非少数人所得而私"作根据 → 解释"促"字出自孙中山遗嘱中的"至嘱"与"最短期间"，把促进变成要求对方兑现其自身承诺 → 说明促进会的两个意义：研究与推动，汇合小流成一条大河 → 转折指出外国宪政是承认已有的民主事实，中国则是争取尚未取得的民主，所以是大斗争；顽固派是宪政的两面派，判据在于"一面谈宪政，一面却不给人民以丝毫的自由" → 由"顽而不固""以损人开始，以害己告终"的公例推出凡属倒退行为结果都和愿望相反 → 落到前途判断：方向由人民和历史规定，顽固派到底是少数，事情困难却大有希望。

##### 33、抗日根据地的政权问题
### 为什么写
一九四〇年三月六日，毛泽东为中共中央起草的对党内指示。文章开篇即交代形势：国民党反共顽固派极力反对在华北、华中等地建立抗日民主政权，而共产党必须建立、并且已经可能在各主要抗日根据地内建立这种政权。围绕政权问题在华北、华中和西北展开的斗争，"带着推动全国建立统一战线政权的性质，为全国观感之所系"，因此必须谨慎处理。具体事由已经临近：河北正在开始召集参议会、选举河北行政委员会，晋西北、山东、淮河以北和绥德、富县、陇东等地也要建立新政权；晋察冀边区、冀中区、太行山区、冀南区等建立已久的政权，则面临按新原则重新审查方针的问题。指示要给同一时间内各地建政提供一个统一标准。

### 主要在解决什么问题
需要解决的不是"要不要建政权"，而是建成什么性质、按什么比例、由谁领导、如何与党外人士相处。文中指认了几种必须纠正的认识：把新政权误解为地主资产阶级的反革命专政，或误解为土地革命时期的工农民主专政，从而在执行上过右或过左；忽视争取中等资产阶级和开明绅士的"左"的倾向，这被判定为目前更严重的偏向；把人员分配当作可以敷衍塞责的说法而不是真实政策；党员不愿和不惯同党外人士合作的狭隘性；以为有军队和政权在手，一切都要无条件地照自己的决定去做；以及把三分之一的规定当成需要机械凑足的数目字。

### 作者最后给出的答案
政权性质是民族统一战线的，是一切赞成抗日又赞成民主的人们的政权，是几个革命阶级联合起来对于汉奸和反动派的民主专政，既区别于地主资产阶级的反革命专政，也区别于土地革命时期的工农民主专政。人员分配定为三三制：共产党员、非党的左派进步分子、不左不右的中间派各占三分之一。领导权由所占三分之一在质量上的优越条件来保证，"不是要一天到晚当作口号去高喊，也不是盛气凌人地要人家服从我们，而是以党的正确政策和自己的模范工作，说服和教育党外人士"。选举权与被选举权只以年满十八岁并赞成抗日和民主为条件，其余身份一概不限；组织形式为民主集中制。比例是大体规定，各地依实际施行。

### 全文怎么推进
形势判断与"必须谨慎地处理"的要求 → 给政权定性，用与两类旧政权的区别划清边界，并声明过左和过右都将造成极坏影响 → 举出河北等地的现实事例，指认目前更严重的是忽视争取中等资产阶级和开明绅士的"左"的倾向 → 提出三三制的人员比例 → 逐份说明每一个三分之一的用意：党员以质量保证领导权，进步分子联系广大小资产阶级群众，中间派用以争取中等资产阶级和开明绅士从而孤立顽固派 → 规定对党外人员的合作态度，教育党员克服狭隘性、遇事先商量，并禁止以军队政权在手强行决定 → 声明数目并非机械规定、各地依实际施行、最下层可变通、老区须重新审查 → 补足选举资格、组织形式、施政方针和对党外人士生活言论的宽容 → 责成各中央局、分局、区党委和军队首长切实执行。

##### 34、目前抗日统一战线中的策略问题
### 为什么写
一九四〇年三月十一日，毛泽东在延安中国共产党的高级干部会议上的报告提纲。文中自述的形势是：日本帝国主义受抗日战争的严重打击，已无力再作大规模军事进攻，敌我处在战略相持阶段，但敌人仍以破坏抗日统一战线、加紧敌后"扫荡"、加紧经济侵略等方法坚持灭亡中国的基本政策；亲日派大资产阶级早已彻底投降，欧美派大资产阶级尚能抗日但妥协倾向严重，并颁布《限制异党活动办法》等磨擦法令，动员一切力量在全国进行思想上政治上军事上的反共磨擦。据注释，中共中央已于同年二月一日作出《关于目前时局与党的任务的决定》，针对国民党投降与倒退的倾向提出十项任务。本报告即在该决定之后，为高级干部统一策略认识而作。

### 主要在解决什么问题
需要纠正的是党内对"斗争"与"团结"关系的几种错误认识，文中逐条点出：认为斗争会破裂统一战线，因而不敢斗争；认为斗争可以无限制地使用，因而不知节制；对中间势力采取不正确的策略；对顽固势力有错误的认识——或者认为大资产阶级抗日派已是事实上的投降派、马上就要举行反共战争，因而放弃争取与合作，或者因为国民党中央颁布磨擦法令就以为整个国民党都是顽固派。此外还有一种疏漏：许多共产党员不知利用国民党自己宣布的纲领作为动员民众、孤立顽固派的武器。

### 作者最后给出的答案
抗日战争胜利的基本条件是抗日统一战线的扩大和巩固，为此必须采取发展进步势力、争取中间势力、反对顽固势力这三个不可分离的环节，并"以斗争为达到团结一切抗日势力的手段"——"以斗争求团结则团结存，以退让求团结则团结亡"。中间势力须分解为中等资产阶级、开明绅士、地方实力派三部分，分别确定可争取的限度；争取能否成功取决于三个条件：我们有充足的力量、尊重他们的利益、对顽固派作坚决斗争并能一步步取得胜利。对顽固派的两面政策施以革命的两面政策，斗争须守自卫、胜利、休战三原则，即"有理""有利""有节"。根据地政权按三三制建立。宣传上把握国民党自己宣布的五条纲领。

### 全文怎么推进
分析政治形势，按矛盾结构把统一战线内部力量划为顽固派、中间派、进步派三方 → 提出三个不可分离的策略环节，确立"斗争是团结的手段，团结是斗争的目的"，并列出必须纠正的四种错误认识 → 说明发展进步势力本身就是严重的斗争过程，不同顽固派坚决斗争并收到成效，就不能消释中间派的怀疑 → 把中间势力分解为三部分，逐部分说明其矛盾结构、政治企图与可争取的限度，并给出争取得以成立的三个条件 → 分析顽固派的两面政策，提出革命的两面政策，再以自卫、胜利、休战三原则为斗争划界 → 指出整个国民党并不等于顽固派，顽固派居支配地位而数量上只占少数，须分别对待 → 规定根据地政权的统一战线性质与三三制人员分配 → 强调争取知识分子 → 给出五条宣传纲领，说明依此行动即为合法、顽固派反对即为非法，同时划清共同纲领与思想体系的界限。

##### 35、放手发展抗日力量，抵抗反共顽固派的进攻
### 为什么写
一九四〇年五月四日，毛泽东为中共中央起草的给中共中央东南局的指示。据编者说明，当时中共中央委员、东南局书记项英思想中存在严重的右倾观点，没有坚决实行中央的方针，不敢放手发动群众，不敢在日本占领地区扩大解放区和人民军队，对国民党反动进攻的严重性认识不足，因而缺乏对付这个反动进攻的精神上和组织上的准备。指示到达后，东南局委员、新四军第一支队司令员陈毅立即执行，项英却仍不愿执行，对可能的反动进攻仍不作准备，以致一九四一年一月皖南事变发生时处于软弱无能的地位，皖南新四军九千余人遭受覆灭性损失，项英亦被反动分子所杀。正文中也留下时间压力的痕迹：中央前要东南局在一年内于江浙两省敌后地区扩大抗日武装至十万人枪并迅速建立政权，而"过去已经失去了时机"。

### 主要在解决什么问题
要纠正的是以"特殊性"为由不执行统一方针、以"统一"为由不敢斗争的右倾认识。文中逐项点出：强调特殊性而不强调同一性；在顽固派坚决执行防共、限共、反共政策的时候仍然强调统一而不强调斗争；以为"我愈发展，彼愈投降，我愈退让，彼愈抗日"；或者走向另一端，以为现在已经是全国分裂的时候、国共合作已经不可能；以及对时局估计和任务提出发生过左过右的意见而不加以说明和克服。后果参照被直接写出：否则"就将再犯一九二七年的错误"。

### 作者最后给出的答案
在一切敌后地区和战争区域应强调同一性——均有敌人、均在抗战，因而"均能够发展，均应该发展"；"发展"被定义为不受国民党限制、超越其所能允许的范围、不要别人委任、不靠上级发饷，独立自主地扩大军队、建立根据地和政权、设立财政经济机关、办学校培养干部。在顽固派执行反共政策时应强调斗争，对其一切法律、命令、宣传、批评提出针锋相对的办法，并从有理、有利、有节即自卫、胜利、休战三原则出发。时局须两面估计：投降危险大大加重，克服的可能仍未丧失；当前冲突是局部性的、是战略侦察和准备投降的步骤，而不是全国性的、马上投降的步骤。各地进展互为条件：江北愈胜利愈发展，顾祝同在江南愈不敢轻动。国民党统治区域则另设方式：荫蔽精干，长期埋伏，积蓄力量，以待时机。

### 全文怎么推进
以同一性压倒特殊性确立"均应该发展"的前提，并把"发展"定义为一串不依赖对方许可的具体动作，附以地理范围、数量指标和进度追问 → 在对方坚决执行反共政策的条件下把重心由统一转到斗争，给出逐项针锋相对的对应办法，并以有理、有利、有节为斗争划界 → 列举斗争对顽固派、对党内、对中间派、对应付突然事变的多重作用，指出不斗争就要重犯一九二七年的错误 → 对时局作两面估计，并按"已经是什么、还不是什么"给当前冲突定级，据此提出三项方针 → 用各地自卫作战与发展的事实说明局部处境由他处进展决定，反驳"我愈退让，彼愈抗日"的相反估计 → 重申敌后根据地政权的统一战线性质 → 区分国民党统治区域与敌后区域，分设隐蔽积蓄的实现方式，同时保持基本方针一致，并相应加严组织保护 → 布置讨论、传达与执行的责任人和期限。

##### 36、团结到底
### 为什么写
一九四〇年七月五日，毛泽东为延安《新中华报》写的纪念抗日战争三周年的文章。文章开头点出两个重合的时间：抗日战争的三周年，正是中国共产党的十九周年，由此引出共产党人在中华民族兴亡上"责任是更大的"。直接由头是中共中央已发表对时局的宣言，"这个宣言的中心是号召抗战到底，团结到底"；文章希望这一方针得到友党友军和全国人民的赞同，而"一切共产党员尤其必须认真地执行这个宣言中所示的方针"。文中给出的形势判断说明了紧迫性：日本帝国主义正准备向南洋侵略、加紧向中国进攻，势将勾引中国一部分动摇分子对其投降，投降危险空前地加重，"抗战的第四周年将是最困难的一年"。

### 主要在解决什么问题
要解决的是团结的边界划在哪里，以及党内两种方向相反的错误。一种是对坚决的投降分子和反共分子容忍，不坚决反对投降派，不打退反共分子的进攻，或者同人家建立无原则的统一战线、不反对溶共限共防共制共的一套——这被判定为右倾机会主义。另一种是不尊重党的统一战线政策，把并非坚决投降和坚决反共的人也推到对立面去，而这些人当中有两面派、有被迫的、有一时之错的——这被判定为"左"倾机会主义。此外还有一项具体的执行问题：某些地方党部尚未严格执行"不在一切友军中发展党的组织"的决定。

### 作者最后给出的答案
"只有抗战到底，才能团结到底，也只有团结到底，才能抗战到底"，因此共产党员既要作抗战的模范，也要作团结的模范。反对的对象被严格限定为敌人和坚决的投降分子、反共分子，"对其他一切人，都要认真地团结他们"；这类坚决者在任何地方都只占少数，作者以一次实地调查为据：某地方政府一千三百人中坚决反共的只有四十至五十人，不足百分之四。对坚决者不能容忍，必须站在自卫立场坚决打退其进攻；对非坚决者必须争取团结。政权上主张各党、各派、各界、各军的联合专政，实行三三制，共产党员只占三分之一；只要不投降不反共，任何人均可参加政府工作，任何党派均应有存在和活动之权。军队上继续执行不在一切友军中发展党的组织的决定。

### 全文怎么推进
由抗战三周年与建党十九周年的重合引出共产党人更大的责任，并把中央宣言的中心确定为抗战到底、团结到底 → 指出两者互为条件，据此要求党员在两方面都作模范 → 把反对面严格限定为敌人和坚决的投降、反共分子，并用一次调查的数字说明这类人不足百分之四 → 对两类对象分别规定政策，并给两侧的失误各起一个名字：容忍坚决敌对者是右倾机会主义，不团结非坚决者是"左"倾机会主义 → 落到政权问题：既不赞成别党一党专政也不主张自己一党专政，主张联合专政与三三制，参加资格只设"不投降不反共"一条 → 落到军队问题：不在友军中发展党的组织，对不磨擦者一律友好，曾磨擦者停止后恢复友好 → 把同一成对要求推广到财政、经济、文化、教育、锄奸各方面 → 分析国际形势的有利与不利两面，判定投降危险空前加重、第四周年将是最困难的一年，最后给出任务与前途判断。

##### 37、论政策
### 为什么写
一九四○年十二月二十五日，这是毛泽东为中共中央起草的对党内的指示。背景是"目前反共高潮的形势下，我们的政策有决定的意义"。但党内许多干部还不明白：党在目前时期的政策，应当和土地革命时期的政策有重大的区别。过去十年土地革命时期许多政策（尤其后期的过左政策）现在不应再简单引用。作者借此系统澄清当前统一战线的策略原则和各项具体政策，纠正把旧阶段政策套用到新阶段、以及由此产生的过左倾向。

### 主要在解决什么问题
要解决的是党内对策略问题的片面观点和过左过右的摇摆。历史上两个极端都造成了极大损失：第一次大革命后期陈独秀右倾机会主义是"一切联合，否认斗争"；土地革命后期"左"倾机会主义是"一切斗争，否认联合"（除基本农民以外）。当前主要危险仍是过左观点——不少人仍用土地革命的过左政策对待抗日统一战线，或对国民党估计错误、对两面分子与坚决汉奸不加区别。作者要回答：在抗日统一战线时期，政策究竟应建立在什么基础上。

### 作者最后给出的答案
抗日民族统一战线政策，"既不是一切联合否认斗争，又不是一切斗争否认联合，而是综合联合和斗争两方面的政策"。它在十项策略原则中展开：联合一切抗日人民、统一战线下的独立自主、战略统一下的游击战争、对顽固派有理有利有节地斗争、荫蔽精干长期埋伏、发展进步势力争取中间势力孤立顽固势力、对顽固派实行革命的两面政策、对汉奸亲日派区别对待、按阶级关系区别、按帝国主义区别。根本方法是"在这些区别上建立我们的政策""利用矛盾，争取多数，反对少数，各个击破"。各项具体政策（政权、劳动、土地、税收、锄奸、人民权利、经济、文教、军事）均须兼顾同盟者、设定合理限度，全党坚决实行，纠正错误要有步骤。

### 全文怎么推进
从"政策在反共高潮中有决定意义"出发 → 指出干部未明当前政策与土地革命政策的重大区别，剖析历史上两个极端错误（右倾一切联合、左倾一切斗争）及其危害 → 确立当前统一战线的综合政策"既联合又斗争" → 展开十项具体策略原则，贯穿"在区别上建立政策"与"利用矛盾争取多数反对少数各个击破"两条主线，特别以对顽固派、汉奸、大地主大资产阶级、帝国主义的多重区别体现差别化 → 逐条列出各项具体政策并强调合理限度、不包办、不滥杀 → 收束：全党必须坚决实行，纠正错误应有步骤，不可操之过急。

##### 38、为皖南事变发表的命令和谈话
### 为什么写
一九四一年一月二十日，皖南事变发生后，新四军奉令北移突遭亲日派阴谋袭击，军长叶挺被俘。本文由两部分组成：一是中共中央革命军事委员会的命令，重建新四军指挥；二是军委会发言人对新华社记者的谈话，揭露事变背后的日寇与亲日派全套阴谋。背景是第二次反共高潮中，亲日派借事变推行投降反共计划，国民党军委会一月十七日更发布取消新四军番号的反动命令。

### 主要在解决什么问题
要解决的是在皖南事变这一严重突发事件面前，如何既不惊慌溃散、又能清醒判明其性质：事变不是孤立偶发，而是投降反共全套计划的开端。问题集中在：如何处置（重建还是瓦解）、如何判断时局前途、如何在坚决斗争的同时保持合作底线、如何既打击亲日派又争取舆论与中间力量。

### 作者最后给出的答案

##### 39、打退第二次反共高潮后的时局
### 为什么写
一九四一年三月十八日，这是毛泽东为中共中央起草的对党内的指示。背景是第二次反共高潮（从何白《皓电》开始，至皖南事变和一月十七日命令达最高峰）已被打退，三月六日蒋介石反共演说和参政会反共决议是"退兵时的一战"。时局可能暂时走向某一程度的缓和。作者在打退高潮之后向党内说明时局判断与下一步工作方针，防止两种偏向：松懈警惕，或误判为最后破裂。

### 主要在解决什么问题
要解决党内在打退高潮后的局势研判与工作方针问题：第一，如何判断"暂时缓和"这一走向，不被表面事件迷惑；第二，如何认识我党退让与反攻政策的正确性，并在争点未决前不松懈；第三，如何在缓和表象下既不放松警惕、又不误判为破裂，继续执行既定正确政策、纠正过左。问题集中在：暂时缓和下，斗争是结束还是进入相持。

### 作者最后给出的答案
（一）时局可能暂时走向某一程度的缓和——因世界两大帝国主义集团斗争前夜、国民党内部多重矛盾、国内人民同情、我党抗议政策均不容许继续紧张，故暂时轻微缓和是蒋介石所需。（二）斗争使国民党地位降低、共产党地位提高，形成力量对比变化的关键，迫使蒋介石重新考虑；其以"民族领袖"姿态维持统治的企图，若无政策实质改变必徒劳。（三）我党先退让（佳电）后反攻（两个十二条、拒绝参政会、全国抗议）、有理有利有节的政策正确且已收效；争点未决前应继续严正抗议、扩大宣传、不松懈。（四）国民党压迫不会放松，须提高警惕、坚决打退进攻，执行《论政策》指示、纠正过左、长期坚持，并反对破裂误判。

### 全文怎么推进
判断时局走向暂时缓和，并分析缓和的四重成因（国际帝国主义集团斗争前夜、国民党内部多重矛盾、国内人民同情、我党抗议政策）→ 指出斗争改变了力量对比、提高了我党地位，蒋介石被迫重新考虑、企图以"民族领袖"姿态维持统治但形式欺骗必徒劳 → 总结我党政策：先退让后反攻、有理有利有节，正确且已收效，在争点未决前继续抗议不松懈 → 警示国民党压迫不会放松、须提高警惕坚决打退进攻、执行《论政策》纠正过左、反对"国共已破裂"的误判。

##### 40、关于打退第二次反共高潮的总结
### 为什么写
一九四一年五月八日，这是毛泽东为中共中央起草的对党内的指示。背景是第二次反共高潮"已经过去了"，继之而来的是国际国内新环境中继续抗战的局面；新增因素有帝国主义战争扩大、国际革命高涨、苏日中立条约、国民党政治地位降低与共产党提高、日本准备新的大举进攻。为了团结全国人民坚持抗日、继续克服投降危险和反共逆流，研究并学习反对这次反共高潮斗争中的教训"是完全必要的"。本文是对这次斗争的系统总结，意在统一党内的策略认识。

### 主要在解决什么问题
要解决党内一部分同志在打退高潮后出现的多种错误认识：把反共高潮误判为四一二、马日事变（重演一九二七年）、忘记民族矛盾是基本矛盾；对英美派大资产阶级的两面性认识不清；对针锋相对、有理有利有节的斗争战术重视不够（项英机会主义失败为戒）；把各派地主资产阶级混为一谈、不能争取中间派；对党的政策发生动摇、想退回土地革命政策；只准备最坏可能性而丢掉好可能性；不理解统一战线政策即阶级政策、民族斗争与阶级斗争一致；以及误解根据地社会性质。问题集中在：如何从这次斗争学到正确教训、避免把复杂政治简单化、避免孤立自己。

### 作者最后给出的答案
总前提是：中日民族矛盾依然是基本矛盾，国内阶级矛盾从属，只要民族矛盾尖锐存在，就不能造成一九二七年的形势。据此八条教训：一、以民族矛盾基本、阶级矛盾从属为总前提研判形势，防重演误判；二、英美派大资产阶级仍两面性，我方取"即以其人之道还治其人之身"的革命两面政策（以打对打、以拉对拉），只要未完全叛变此政策不变；三、须针锋相对地作战，且有理有利有节三者缺一不可；四、区别买办性大资产阶级与民族资产阶级、最反动大地主与开明绅士，以争取中间派、实行三三制，中国"两头小中间大"必须争取中间阶级；五、党的正确政策（十二月二十五日指示）仍适用，不能退回土地革命政策；六、准备最坏可能性但不抛弃好可能性，充分准备反而使对手不敢破裂；七、统一战线政策即阶级政策，民族斗争与阶级斗争一致；八、根据地社会性质已是新民主主义，判定以政权人民性＋党的领导为原则，而非土革程度。

### 全文怎么推进
开篇点明高潮已过、新环境到来，总结教训必要 → 立总前提：民族矛盾基本、阶级矛盾从属，不能把高潮估为一九二七年重演 → 推导对英美派大资产阶级仍取革命两面政策（以打对打以拉对拉）→ 作战须针锋相对、有理有利有节三者缺一不可，项英为戒 → 区别各阶级各派以争取中间派、实行三三制，批评"混为一谈"的简单化 → 随后澄清四类错误认识：政策动摇想退回土革、只备最坏丢掉好可能、不理解统一战线即阶级政策、误判根据地社会性质 → 收束于统一党内策略认识、防止自陷孤立。
